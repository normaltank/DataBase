## 本次实现

- 来源目录沿用机构、期刊、其他出版物及采集入口的既有范围。搜索、按需展开的筛选、常显且可单独移除的条件、结果与卡片依次排列。机构类型、期刊主办国别、国际定位和收录范围分别表达；类型切换继续清除不适用条件，国别待确认与国际定位未知保持。
- 来源卡片与人物卡片统一题名、原名、状态及主入口层级，题名自然换行，多标签可换行，无头像如实显示。人物目录显示已用搜索词，整页人物返回仍保留目录搜索条件。
- 来源详情保留介绍与来源内容前置，之后分为来源信息、关系与作品、研究笔记、依据与核查。按真实存在的分组提供章节按钮；机构关系、机构署名、任职、文章单位、发布作品及主办刊物分别保留，期刊国别与国际定位依据分别展示。
- 人物整页分为人物介绍、任职经历、已确认作品、研究笔记、依据与档案信息；作品搜索重新渲染后仍能定位其章节。编辑与导出直接可见，修改历史、比较合并和身份整理历史放入明确的“历史与身份整理”入口。现有资料返回、旧编号解释、作者/权限提示与身份纠错规则保留。
- 章节组件首个提交为 `2304b515180438332fcd0d2d0d00f8c42364d505`，已优先提供父任务及 #22 复用。`sectionNavigation([{id,label},...], ariaLabel)` 返回按钮导航；外层 `data-section-scope` 限定目标，既有标题提供唯一 id。键盘激活后焦点到标题并滚动到可见位置，不修改 hash；目标位于折叠区时先展开。组件只处理章节定位，不管理领域数据或路由。

文件归属：`static/sections.js`、`sections.css` 为公共章节组件；`sources.js`、新增 `sources.css` 与 `people.js`、`people.css` 处理本任务页面；`templates/index.html` 加载对应文件；`scripts/check_profiles_browser.py` 为公开边界浏览器检查。未改 `sources.js` 的 `systemPage()`，未改后端、权限、提交接口、公共视觉变量或编辑器。

## 实际红→绿与回归

使用真实 Microsoft Edge（Playwright、headless），应用通过 `--no-import` 在独占端口 8872 启动，数据为独立临时库内通过公开 HTTP 创建的合成来源、人物、作品、任职、目录译稿和笔记。启动前拒绝未知监听，清理仅终止本次创建的进程；未访问真实 8848、其他 Agent 的 8874、研究库或 ThinkTank。

1. 人物章节检查先因缺少“人物章节”导航失败；接入组件后，键盘逐章定位、标题焦点、hash 不变和返回目录保留查询通过。
2. 来源筛选检查先因缺少“筛选条件”展开入口失败；实现后，国别与国际定位组合、应用后收起但条件常显、单项移除以及切到机构后清除期刊条件通过。
3. 来源章节检查先因缺少“来源章节”导航失败；实现后，来源内容、信息、关系、笔记与依据均可键盘定位，期刊主办国别与国际定位依据仍可查。
4. 人物维护检查先因缺少“历史与身份整理”入口失败；实现后可打开历史及比较人物窗口，作品检索更新后章节按钮仍聚焦真实标题。
5. 响应式回归实际操作 1440、1024、390、320px 下的来源目录/详情/关系/编辑，人物目录/整页/编辑/历史/比较选择及比较预览。长题名、变音原名、多标签、长 URL、无头像、长任职依据与八列表格进入合成样本；正文表格局部横滚，关系章节标题不被窗口页头遮挡。
6. 两成员分别在来源与人物编辑窗口制造真实版本冲突，确认当前姓名输入保留；320px 冲突比较无全页溢出。关闭后从“我的草稿”继续并明确选择“恢复草稿”，输入与冲突提示仍保留。没有静默覆盖另一成员的新版本。

最终六项浏览器检查通过，无页面脚本错误。43 个页面/窗口状态的实际计算样式审计均无必要文字小于 14px、无整页横向溢出。已查看桌面来源目录、手机人物长页、320px 来源详情、比较预览及冲突窗口的实际截图；截图不替代权限证明。公共骨架提供的对比目标沿用，最终全站颜色对比、完整后端检查、双系统 CI 与双轴审查由父任务执行，本任务未重复全量后端套件。
