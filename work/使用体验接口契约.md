# 使用体验接口契约

2026-10-23，指挥 Agent 初定，建设 Agent 实现后补充已落实状态。产品范围见 [规格](../docs/specs/使用体验与UI改进.md)。新增字段兼容旧响应，不迁移业务库。

## reading_access

所有资料 summary 和 detail 增加 reading_access：

```json
{"original_url":"https://example.org/article", "official_files":[{"url":"https://example.org/file.pdf", "label":"官方文件链接"}], "platform_files":[{"id":"attachment-id", "name":"原文.pdf", "url":"/api/attachments/attachment-id"}], "has_body":false}
```

无值时字符串为空、数组为空、has_body 为 false。original_url 为当前条目合法 http(s) 原文地址；official_files 从 raw_json.imported_attachments 提取合法 http(s) 链接并去重，不返回本地路径，不假定全部是 PDF；platform_files 仅当前资料版本的附件，沿用下载权限；has_body 表示已保存网页正文。摘要不算正文。外链安全处理沿用现有公共方法，拒绝危险协议和凭据地址。构建 summary 避免每条重复扫描全库或额外客户端请求。

## 工作台

GET /api/dashboard 保持原字段，新增 my_work：最多 4 条当前用户负责作者且可编辑的内容条目，按真实 updated_at 降序，采用普通 summary 格式。旧资料尚未确认作者时不冒充本人作品。其他可见专题沿用现有 collections 接口；本机草稿沿用按账号隔离的浏览器存储。前端不得将最近更新说成最近阅读。

## 复制文字

GET /api/records/<id>/copy-text，响应 {"mode":"citation|excerpt|references|note", "text":"...", "notice":"..."}。

- 原始资料 citation：已有题名／原题名、作者、日期、刊物、DOI、原文地址、稳定编号和版本；缺失值省略，不补造。
- 有 evidence_record_id 的研究笔记 excerpt：原文摘录、译文、研究说明、定位及引用时保存的原文出处与版本，当前笔记署名与编号。避免把当前原文资料覆盖其保存的出处。
- 普通研究笔记 note：题名、署名、正文纯文本、已有原文关联的当前出处（明确是关联资料，未固定引用快照），不得伪造引用时版本。
- research_report / compilation 为 references：仅输出其采用的笔记／摘录快照与出处，标明采用版本。使用已有 evidence 权限过滤逻辑，当前不可读内容不进入复制文本；可以用不含题名、编号或数量的通用 notice 说明“仅包含当前可查看的引用”。没有引用时给明确空状态，不能伪造内容。
- directory_translation 按 citation 处理，保留覆盖范围和已有署名即可。

端点只读、需登录；权限与详情一致；返回纯文本，不把富文本标签原样当正文。前端成功后提示已复制，剪贴板受限则展示可选择文本。按钮标签依 mode 为复制出处／复制摘录与出处／复制引用清单／复制笔记与出处。

## 阅读说明

无需新端点／新类型。POST /api/records 使用 kind=research_note、linked_ids=[原始资料 ID] 及现有标题、正文、负责作者字段。无 evidence_record_id，不是正式引文摘录。详情已有 cited_by 可筛选普通研究笔记（无 evidence_record_id），显示署名及时间；若 summary 缺署名，增加 author_name 即可。创建后刷新原文详情的关联内容。

- summary（含 linked_records、cited_by、excerpts、专题条目和工作台条目）与 detail 均带 reading_access、author_name；不增加客户端逐条请求。附件／作者映射在单次请求内共用。
- imported_attachments 真实结构为字典列表，字段 name/url/type/sha256/sharing_status；只从 url 提取链接，标签固定为“官方文件链接”，不根据扩展名宣称 PDF 或存档。当前平台文件同时要求附件归属、本版本引用及文件存在；失效／历史／他条资料的附件不进入 platform_files。
- has_body 使用服务端已净化的正文派生文本判断；仅摘要、空段落或空编辑器不算已有正文。链接只做格式与安全协议校验，不联网判断可达性。
- my_work 限已确认负责作者为本人、当前可见且可编辑的 research_note/research_report/compilation，最多四条，按 updated_at 降序；不把上传者或获授权编辑者当负责作者。
- 复制引用没有任何当前可见条目时，text 为“暂无可复制的引用。”；与完全无引用使用同样 notice，不透露隐藏题名、编号或数量。普通笔记采用快照未保存关联原文题录时，不用其最新关联补造采用时出处。普通笔记自身复制则明确显示当前关联资料与“未固定引用快照”。
