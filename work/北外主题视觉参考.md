## 官方依据

### 1. 校徽正式颜色说明：有颜色名称，未见标准色数值

[北外主站「校训校徽校歌」](https://www.bfsu.edu.cn/xxgk/xxxhxg.htm) 明确说明校徽使用黄、黑、蓝、白四种颜色，白色为底色。关键原文：“颜色由黄、黑、蓝、白相间协调组成，白色为底色。”页面未标发布日期，本轮读取日期为 2026-10-22。

这是本轮最可靠的校徽颜色文字依据。它可以支持蓝、黄、白等色彩与北外校徽存在官方说明中的联系，但没有给出各色的 RGB、CMYK、Pantone 或 HEX 数值，也没有单独将蓝、黄指定为所有应用场景的统一主色／辅助色。

### 2. 管理办法：公开通知可读，PDF 附件本轮未能读取

[党委办公室、校长办公室《关于印发〈北京外国语大学校名、校徽使用管理办法（试行）〉的通知》](https://dxb.bfsu.edu.cn/info/1211/4462.htm) 发布于 **2021-11-26**。通知说明办法经 2021-11-16 校长办公会审议通过，并提供管理办法 PDF 和使用申请表附件。本轮通过页面原始正文核实了通知及附件名称；通知正文没有列出蓝、黄的标准色数值。

管理办法 PDF 的公开下载入口返回验证码页面，本轮没有读取附件正文。因此不能声称该办法不含色值或视觉规范，也不能据此断言学校没有完整 VI 手册；只能确认本轮可读的通知正文不提供这些数值。

### 3. 官网实际使用：可作网页参考，不能替代 VI 规范

[北京外国语大学官网首页](https://www.bfsu.edu.cn/) 是当前官方网页呈现的直接参考入口。本轮读取到持续更新的学校内容；首页为动态页面，没有单一发布日。网页中的校徽素材、布局和页面用色属于特定网站版本的实现，不能仅因出现在官网上就认定为学校正式 VI 标准。

本轮未进行页面截图取色，也未将页面 CSS 中的任何颜色数值列为官方标准。后续若参考官网视觉效果选取项目色值，应标注为“项目建议色／官网风格参考”，与上一节的校徽颜色文字说明分开。

## 标准数值的核查结论与边界

- **蓝、黄的 RGB／CMYK／Pantone／HEX：本轮均未找到可据以确认的公开官方数值。** 因而本笔记不提供所谓“北外标准蓝”或“北外标准黄”的数字。
- 已读有效官方入口为校徽说明页、管理办法通知页和官网首页；另检索了 `bfsu.edu.cn` 下与校徽、标准色、RGB、CMYK、Pantone、视觉识别有关的公开结果，未取得可确认的校级常设标准色表。检索未找到不等于规范不存在。
- 校友会旧版「北京外国语大学标识」链接虽有线索，但本轮直接访问返回 404，未列为已读取依据；校友会会徽征集、周年活动标识也不作为学校常设 VI 标准。
- 仍未解决的真实问题是：管理办法附件是否含色值，以及是否另有未检得或未公开的常设视觉识别手册。若将来取得正式色表，可据其明确版本修订项目配色；在此之前，项目中的所有精确色值都应保留“建议值”身份。

## 应用配色建议（全部为项目建议，不是北外官方标准色）

下列 HEX 为本资料平台的屏幕阅读场景选配；没有把它们称为北外官方蓝、官方黄，也没有从校徽位图取色后充当规范。白／浅灰承担主要阅读面积，蓝用于导航与主要操作，黄作为少量强调。实际舒适度仍需在表格、表单和长列表中验证。

| 用途 | 建议色 | 使用方式 |
| --- | --- | --- |
| 主蓝 | `#234E78` | 主按钮、链接、当前栏目及少量页眉 |
| 主蓝悬停 | `#1B3F63` | 主按钮悬停／按下状态 |
| 内容白 | `#FFFFFF` | 表格、表单、正文阅读面 |
| 页面浅灰 | `#F5F7FA` | 阅读面外的页面底色 |
| 柔和金黄 | `#D4AF54` | 小面积装饰、收藏强调；配深色字 |
| 浅暖底 | `#FAF5E8` | 少量需要突出说明的区域，配正文色 |
| 正文深灰蓝 | `#25364A` | 标题、表格与正文 |
| 次要文字 | `#5B6B7C` | 日期、来源等必要元数据 |
| 选中浅蓝 | `#EAF1F8` | 当前行、选中筛选项；配主蓝文字 |
| 细分隔线 | `#D5DEE8` | 装饰性表格分隔；不单独承担控件或状态识别 |

对建议色按 sRGB 相对亮度计算，白字／主蓝约 **8.63:1**，正文／白底约 **12.32:1**，次要文字／白底约 **5.47:1**，正文／金黄约 **5.90:1**；白字／金黄只有 **2.09:1**。因此金黄不用于白底正文或白字按钮；选中状态还应有文字、形状或位置提示，不能只靠黄色变化。

以上是色对计算，不是应用已通过无障碍验收。普通文本采用至少 4.5:1 的对比目标，依据 [W3C WCAG 2.2 文本对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。实际实现还需检查透明度、悬停、禁用与焦点状态。

## 布局与文案建议

- 页面以白底阅读、清晰标题和稳定表格为主。蓝色集中于导航、链接和主要操作，黄色控制为细线或小块强调，避免大面积高饱和黄、渐变横幅及强烈阴影。
- 正文和操作文字建议 15–16 px；必要的次要文字尽量保持 14 px，不靠缩小和淡化文字塞入更多说明。这里是应用建议，不是北外字体规范。
- 删去重复的功能介绍、装饰性英文副标题及不影响使用的宣传语。栏目名称直接描述任务，如来源目录、资料库、收藏。
- 保留影响判断的来源、核对状态、日期和必要操作提示；错误、权限与字段约束说明在相关位置出现。删减文案不应抹去数据依据或待核状态。
- 校徽若进入应用，使用官方原件并保持原有比例和图案；本建议调的是应用界面，不能据此重涂校徽或声称已完整遵循官方 VI。
