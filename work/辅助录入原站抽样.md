# DOI／文章 URL 辅助录入：原站有限抽样

核查日期：2026-10-26（Asia/Singapore）。状态：只读调研证据，供首版规格及适配选择参考；不是实现或验收结果。

## 问题、范围与方法

本次只判断：成员提供一个 DOI 或文章 URL 时，能从一手 API／文章页直接取得哪些题录候选字段，以及哪些值仍须人工确认。范围为一个 DOI、同篇期刊页、两篇智库页；不代表各站覆盖率或长期可用率。

原始输入是下列公开 URL。使用本机 Python 标准库 `urllib.request.urlopen` 进行普通 HTTPS GET，读取响应状态、Content-Type 和 HTML 中的题录标签／标题／署名区；使用 `HTMLParser` 和局部标记核对字段。没有提交表单、登录、绕过访问限制或跟随 PDF 链接，没有抓取和保存正文／PDF。这里保留的是题录观察记录，不是原件快照。

另用 web 浏览工具打开同样 URL 作交叉观察。两种访问环境结果不同的地方分别记录，不能将浏览工具失败推成原站资源不存在。页面中与题录无关的脚本、表单及文字只作为网页数据处理。

## 1. 可用 DOI API：Crossref

输入及一手证据：[Crossref works 单条响应](https://api.crossref.org/works/10.22364/luzv.21.08)。本机 GET：**HTTP 200**，`application/json`。响应 `message.DOI` 与请求相符。

实际可取得：

- `title[0]`：Grāmata par Latvijas sievietēm starpkaru posmā – recenzenta pārdomas。
- `author[]`：姓名拆为 `given`／`family`；本样本为 Ēriks Jēkabsons，含 ORCID URL，但 `authenticated-orcid=false`，`affiliation=[]`。保留原文署名作为候选，不据 ORCID 或姓名自动合并本地人物档案。
- `published.date-parts` 与 `published-online.date-parts`：均为 `[2026,6,30]`；`published-print` 缺失。
- `container-title[]`、`publisher`、`type=journal-article`、`issue=21`、`page=137-145`、两个 `ISSN` 值。
- `URL` 为 DOI 解析地址；`resource.primary.URL` 为期刊文章页。`link[]` 提供 PDF 地址和内容类型信息，只能作为附件线索，未下载。
- `abstract` 是带 `<jats:p>` 的字符串，不能直接当安全 HTML 渲染；仅说明有摘要候选，不据此认定已获取全文。
- `language`、`volume` 缺失；缺失不能填默认语言／卷号。页码保持原字符串或有依据地拆分，不把期号改作卷号。

该单条实际响应已证明本 DOI 的 API 路径可用；本次未完成 Crossref 全接口、配额及服务条款调研，不据一个成功样本承诺所有 DOI 均可解析。web 工具对该 API URL 返回“不可访问”，没有可用 HTTP 状态；本机 200 是此次 API 可用的直接证据。

## 2. 可用文章页：journal.lu.lv

一手证据：[期刊文章页](https://journal.lu.lv/luzv/en/article/view/3250)。本机 GET：**HTTP 200**，`text/html; charset=utf-8`，最终 URL 与输入相同。网页生成器标记为 Open Journal Systems 3.5.0.5；此次观察的是该页，不能外推全部 OJS 站点。

HTML 的 `meta[name="citation_…"]` 提供：

- `citation_title`、重复可出现的 `citation_author`、`citation_author_institution`。
- `citation_journal_title`、`citation_journal_abbrev`、`citation_issn`。
- `citation_language=lv`、`citation_date=2026/06/30`、`citation_issue=21`、`citation_firstpage=137`、`citation_lastpage=145`。
- `citation_doi=10.22364/luzv.21.08`、`citation_abstract_html_url`、`citation_abstract`、`citation_pdf_url`。

同时存在 `DC.*` 元数据，可用于核对：`DC.Title`、`DC.Creator.PersonalName`、`DC.Identifier.DOI`、`DC.Date.issued`、`DC.Language` 等与上述字段对应；`DC.Description` 分 `lv`、`en` 两条，不能用单值字典静默覆盖。`citation_abstract` 含 `&nbsp;`，需要实体解码。以上依据均为该[文章页源数据](https://journal.lu.lv/luzv/en/article/view/3250)。

对同篇文章的交叉观察与适配含义：

- 题名、署名、DOI、发表日期、期号、页码与 API 一致。网页提供语言 `lv` 和署名单位，而 API 的语言缺失、作者机构列表为空；这是各来源字段覆盖差异，应按字段显示出处。
- 网页 `citation_issn` 只有 `2592-9593`；API 有该值及 `2500-9621`，本次未独立核实二者的载体类型，不擅自标为纸本／电子版。
- 网页日期还包括创建／发表 `2026-06-30`、提交 `2026-07-02`、修改 `2026-09-02`。修改日期或提交日期不能替换发表日期；不同日期类型的先后也不在本次解释成编辑错误。
- 输入路径含 `/en/`，文章 `citation_language` 却是 `lv`；界面语言和材料语言须分别理解。网页给出的文章地址不含 `/en/`；保留输入 URL、实际最终 URL 及元数据声明的文章 URL，不能把三者混成一次 HTTP 重定向。
- `DC.Type.articleType=Reviews`，而 API 类型为 `journal-article`；这是粗细不同的类型描述，不能自动转为平台既有的某一业务分类。

web 工具打开该页失败且未提供 HTTP 状态；本机普通 GET 成功。未读取网页标示的 PDF。

## 3. 无 DOI 智库：Providus，兼作结构化信息缺失样本

一手证据：[Providus 研究页](https://providus.lv/petijumi/petijums-kas-latvija-nebalso-nevienlidzigas-demokratijas/)。本机 GET：**HTTP 200**，`text/html; charset=UTF-8`，最终 URL 不变；web 工具亦成功读取该页。

- `og:type=article`、`og:locale=lv`、`og:url`、`og:description` 及 `meta[name="description"]` 有值；`rel=canonical` 提供带末尾斜线的页面 URL，`og:url` 不带末尾斜线。
- **`og:title` 是空字符串**；标题可从正文唯一 `<h3>` 和 HTML `<title>` 取得。页面标题为 Pētījums “Kas Latvijā (ne)balso?: Nevienlīdzīgās demokrātijas”。`<title>` 还含站名后缀及 HTML 实体，不能原样当文章标题。
- 作者区有 `Autori` 标示，`p.article-persons .article-persons--name` 为 Līga Stafecka，并链接该站人物页；这是署名证据，不是已核实的任职关系。
- 本次取得 HTML 未见 `citation_*` 或 `application/ld+json`，未见 DOI 标签、`datePublished`、`article:published_time` 或 `<time datetime>`。应记录“本样本未取得 DOI／发表日期”，不能声称报告一定没有 DOI，也不能从图片／PDF路径的 `2026/06` 猜发表日期。
- PDF 链接存在，仅记录可用原文线索；未打开 PDF，也未证明 PDF 内的作者或日期与网页相同。

因此，单用 OG／通用 JSON-LD 不能完整处理此页。首版若只有结构化通用提取，应展示已得描述／URL及缺项，让成员补录；若增加此站适配，可明确使用标题和署名区定位，但仍保留日期缺失。OG description 是网页说明候选，本次未判断其等同正式摘要。

## 4. LIIA：有限题录与一次访问失败

一手证据：[LIIA 文章页](https://liia.lv/en/opinions/sustaining-baltic-deterrence-a-targeted-strategy-for-latvian-and-eastern-flank-advocacy-1610)。本机普通 GET：**HTTP 200**，`text/html; charset=UTF-8`，最终 URL 不变。web 工具同 URL 返回 **406 Not Acceptable**；未进行绕过尝试。这是工具／访问环境差异的实际失败样本，不代表该资源普遍不可访问。

- `og:title`、`twitter:title`、HTML `<title>` 和 `<h1>` 一致：Sustaining Baltic Deterrence: A Targeted Strategy for Latvian and Eastern Flank Advocacy。
- 作者在 `p.author strong a`，署名 Michael Crane；这是专站 DOM 位置，不是通用结构化作者标签。
- `og:description`、`twitter:description` 和 `meta[name="description"]` 都只有 `.`，属于不可用描述，不能把非空就算有效字段。
- 有 `og:url`；另有非标准形式 `meta[name="canonical"]`，声明 `http://` 地址，与实际 HTTPS 页面不同。应保留来源差异，不降级访问协议来迎合该声明。
- 未见 `citation_*` 或 JSON-LD；本次未取得结构化 DOI、发表日期及材料语言。页面路径 `/en/` 只能作语言线索，不能视为已核实材料语言。

首版面对 406 或其他抓取失败，应返回可理解的失败结果并保留成员输入，允许人工录入。此次没有独立实现或测试这些行为。

## 建议交给实施者的最小边界

以下是依据样本提出的实施建议，最终范围由已确认规格决定：

1. **DOI → Crossref 单条题录候选**：先验证响应 DOI，保留每个候选字段的来源 URL和取得日期。空值、日期精度及多值数组如实保留；API无记录与网络失败分别处理。
2. **文章 URL → 本样本 `citation_*`／DC 题录**：适配 journal.lu.lv 这类已核实标签；重复标签保留数组。通用 OG 可以补充线索，但不能填平空标题、无作者、无日期等缺项。
3. **所有提取都是待人工确认的候选**：同字段存在差异时展示来源和值；不得自动确认本地来源归属、人物身份或“已核对”。保留用户填写值，正文／附件下载、全站发现、自动入库和批量采集不由本报告扩大授权。

## 本轮检查与限制

- 软件证据：仅运行公开 URL 读取和字段检查脚本；未开发解析器，未运行应用测试，未改数据库。
- 资料忠实性：核对上述四个公开响应及局部 HTML 位置，记录 API／网页一致项、缺失及访问差异；未核对 PDF、期刊全卷目录或智库报告原件。
- 研究论证：本报告只支持“这些具体响应可以提供哪些候选字段”，不评价材料观点、作者影响力或平台总体研究能力。
- 跨人复用：给出可独立访问的原站 URL、字段名和实际状态；尚无研究员接续复核。本次有限样本不证明站点覆盖率、稳定性或通用提取准确率。
