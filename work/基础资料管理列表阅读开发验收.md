# 基础资料管理列表与阅读：开发验收

2026-10-25；开发自测记录。任务 [#15](https://github.com/normaltank/DataBase/issues/15)，依据 [基础资料管理第一批](../docs/specs/基础资料管理第一批.md) 1.0（固定规格基线 `de0ddf4`），提交前已合入集成分支 `7bfb242`。本记录不代表指挥方独立验收、PR 合并或正式部署。

## 本轮实现

`static/library.js` 与 `static/library.css` 聚合列表、卡片切换、连续阅读及选择状态。`app.js` 仅增加资料库路由、会话清理和挂载钩子，并允许列表模板接收已取回的同一组结果；`ux.js` 让既有阅读模板接受可选目标容器。`templates/index.html` 加载新模块。保持现有资料身份、权限、正文、笔记、引用、署名和文章单位功能。

- 视图切换保留查询、筛选、排序、页码和选择。长题名不截断，署名、日期、出处、类型和核对状态可读。
- 桌面保留结果列表，在旁边阅读当前页的上一条／下一条，明确显示本页位置。核心题录后优先正文、摘要和附件；作品署名及文章单位完整保留在后部默认收起区。窄屏使用全屏阅读，提供返回列表、Escape 和焦点循环；关闭时恢复原入口焦点和页面位置。
- 逐条勾选、选择当前页和清空选择；同一条件跨页保留，查询／筛选／排序或入口改变时清空并反馈。最多 100 条，仅使用明确勾选的稳定编号；本轮没有显示尚未实现的批量操作按钮。
- 选择只在内存中保存，重新加载不恢复旧授权。会话变化清空选择、阅读和缓存；页面重新获得焦点／可见时重新核验当前选择、阅读权限及当前页，撤权内容退出列表和阅读区域。

## 后续接入接口

供 [#16](https://github.com/normaltank/DataBase/issues/16) 使用：

- `window.librarySelection.ids()` 返回当前所选稳定编号数组的副本；`count()` 返回数量；`clear(message='')` 清空并可反馈；`limit` 为 100。批量动作仍须在服务端重新检查全部编号和权限。
- `library:selection-change` 的 `detail` 为 `{ids,count,limit}`，逐条勾选、当前页选择、清空及上下文变化时发布。
- `library:rendered` 在资料库 DOM 挂载后发布，`detail={root,items}`；动作区挂载到该 `root` 内的 `[data-library-batch-actions]`。路由和保存后的背景刷新都会重新挂载。

供 [#17](https://github.com/normaltank/DataBase/issues/17) 使用：紧凑列表通过存在性检查调用 `attachmentMatchSection(record)`，保留 `[data-library-attachment-matches]` 容器。阅读复用 `uxReadRecord(record,target=null)`；读取完成发布 `library:reader-rendered`，`detail={record,root}`。既有详情默认仍打开抽屉，连续阅读传入自身容器。
