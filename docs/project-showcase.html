试用程序：在 Windows 10/11 64位系统完整解压程序包 → 双击 start.bat → 按使用说明登录；结束时双击 stop.bat。本页独立演示，不会启动程序。

本包另有27个辅助机构；56篇资料中，23篇含独立原译摘要节选、33篇无原始摘要。本页题录与摘要节选来自本包公开样本快照（2026-10-30），只选取3篇；原文与机器译文分别截断，不代表全文或完整摘要。机器中文尚未人工校订，题录核对状态仍为待核对。原始署名保留，不据姓名推认作者身份。

资料底座展示资料流转方式；发现来源和纸页变化为流程示意，不表示38个核心来源全部已接通自动采集。本页没有实时采集、翻译或业务保存。实际程序支持的范围与使用方法以包内说明为准。

主题与期刊均为协作情景：研究员在自己的设备写作，平台接收原件、交接与版本。负责人资格由管理员维护；当期负责人组织及审稿，普通研究员不因此取得负责人资格。研究员可在库内或库外选文，原文可以之后补关联。完整的结构化期刊卷期、目次和年度指标仍是后续建设方向，本页不表示这些结构已交付。

研究对象与期刊主办国分别记录；题录、链接与实际保存的原件也分别理解。只有主动点击“题录出处”或下方参考链接才离开本页联网。
