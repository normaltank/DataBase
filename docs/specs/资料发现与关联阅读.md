# 资料发现与关联阅读

版本：1.0；日期：2026-11-08。状态：按用户对资料发现方向及“按你的想法去完善、落实计划”的授权冻结，待施工与独立验证。任务状态由 GitHub Issues 维护。继承 [PRODUCT](../../PRODUCT.md)、[GLOSSARY](../../GLOSSARY.md) 及既有资料阅读、权限和批次规则；本批不改变核心业务含义。

## Problem Statement

资料已有国别、发表日期、首次收录日期、来源和已确认作者等信息，但使用者主要依靠多层筛选与逐篇打开来发现资料。缺少地图和时间分布入口，勾选多篇后也无法直接对照；文章与人物、机构及相关成果的关系散落在详情中。用户指出分类堆叠会降低可用性，期望直观而实用的交互。

## Solution

在现有资料列表内提供按需展开的地图与时间浏览，从分布直接筛选原列表；在阅读处提供当前资料的一跳关联，跳回真实档案或相关资料；选中2–3篇即可比较题名、原文、摘要、作者、来源、日期及阅读可用性。保留紧凑列表、既有蓝白灰和淡金状态配色、原文出处及现有返回位置，不新增孤立总览页。

## User Stories

1. 作为研究员，我能按研究对象国点击地图，直接看到对应资料。
2. 作为研究员，我知道地图展示当前查询下的库内资料数量，不据此判断国家研究热度或完整覆盖。
3. 作为读者，我能通过等价的国别按钮或列表完成筛选，不必精确点击小国。
4. 作为读者，我能找到没有可映射国家、历史地区或未知国别的资料，不被地图遗漏。
5. 作为读者，我能切换发表、首次收录或最近修订的时间分布，并点击年份缩小查询。
6. 作为研究员，我能辨认只有年份、只有年月和日期未知的资料，界面不会补造具体日期。
7. 作为使用者，我在地图或时间筛选后保留关键词、固定来源、资料夹及新文章批次等原范围，并能清除新增条件。
8. 作为读者，我看到当前完整可见查询的分布，翻页不会改变计数，也不会看到无权资料的数量或关系。
9. 作为新文章读者，我的分布、列表、返回及导出继续使用同一冻结查询成员；后台晚到内容不混入当前结果。
10. 作为读者，我能从当前文章看到已确认作者、发布机构或刊载期刊，并直接进入档案。
11. 作为读者，我能区分已确认作者与原始未确认署名，任职与文章署名单位分别表达。
12. 作为研究员，我能沿已存在的原文与成果联系继续阅读，关系缺失时如实显示，不生成关系或推断影响力。
13. 作为读者，我从关联档案返回后仍保留查找条件、页码及可恢复的阅读位置。
14. 作为研究员，我选中2–3篇资料便能并排比较，毋须来回打开记忆内容。
15. 作为研究员，我能比较中文与原文题名、原始及中文摘要、来源、署名、发表与收录时间和可用内容，并知道机器中文状态。
16. 作为读者，我能从比较处进入其中一篇的阅读或原文，取消比较后保留原选择与列表位置。
17. 作为使用者，我在选择数量不适合、资料不可访问或请求失败时得到可执行的恢复提示，界面不静默少掉一篇。
18. 作为键盘、手机和放大显示使用者，我能完成展开、筛选、返回、比较及档案跳转，焦点与状态可辨认。

## Implementation Decisions

- 三项完整流程分别实施：地图与时间浏览、单篇一跳关联、少量已选资料比较。地图和时间为同一查找工具；关系与比较均在已有列表／阅读流程中按需打开。普通资料列表首屏保持紧凑。
- 地图展示资料研究对象国，不混用机构所在地、期刊主办国或作者任职国。使用有公开来源和许可的国家边界资源，本地提供；本轮不做机构精确落点、地理编码或外部地图服务。地图是资料发现入口，不声明边界研究结论；无法映射的值仍可从文字入口查找。
- 分布来自完整可见查询而非当前分页，沿用既有检索、国名标准化、保存检索、批次及实时权限逻辑。可以新增只读聚合响应；不额外批量取得正文，不将统计端点变成权限旁路。
- 时间分布按明确日期角色分组，实际精度保留；年份选择转换为现有范围条件，日期未知有独立入口。图表说明数量口径，多国资料可计入多个国别，不能将各国计数之和误写为去重总量。
- 地图、时间浏览的展示状态可以独立保留，但展示模式不是业务筛选或新的冻结批次条件；改变筛选时清理页码，保留固定范围。保存／导出继续使用有效查询。
- 一跳关联复用已存在并经当前账号可见性检验的档案和资料关系。已确认作品署名、原文／成果关系分别标名，未确认原始署名仍可阅读；不按姓名合并人物，不把发布机构当作作者任职单位，不把图形连线当作新增事实。
- 比较严格使用当前账号显式选择的2–3个稳定资料ID，逐条执行实时权限检查。保留现有选择上限及跨页选择语义；不自动选前三条、扩大研究范围或生成比较结论。展示缺项，失去访问权时明确告知并提供恢复操作。
- 新界面继承现有 Operate／Read 设计，不改主导航顺序，不新增分析评分或装饰性数据大屏。请求必须处理加载、空态、失败、晚到响应、账号和路由切换；减少动画偏好生效。
- 无数据库语义迁移、后台任务、付费AI调用或实际研究材料导入；独立于尚未完成的期刊指标与完整目次范围。

## Testing Decisions

- 沿用已授权的公开HTTP、真实浏览器及隔离合成库接缝；必要时只对新临时目录恢复。验证用户可见结果和权限边界，不用字符串镜像实现测试充当行为证据。
- 分布接口覆盖超过一页资料、组合筛选、多个国家、别名、未知日期、部分日期、隐藏资料、保存检索及新文章冻结成员；核对列表／聚合／导出的同一口径，权限撤销实时生效。
- 关联流程覆盖已确认作者、同名未确认署名、来源角色、可见及不可见相关资料，实际跳转和返回。
- 比较覆盖2篇和3篇、跨页选择、机器中文和原文、缺摘要／日期、不可访问和请求失败；关闭后恢复原列表及选择。
- 实际浏览器检查1366px、390px、320px、200%缩放及键盘；核查地图点击、文字替代、年份切换、清除条件、阅读往返、无脚本错误和横向溢出。保留合成截图证据。
- 最终检查绑定集成提交，执行相关回归和完整必要检查、impeccable机械检测，以及独立Standards／Spec双轴审查。软件通过不表示实际资料覆盖或研究结论已经验证。
