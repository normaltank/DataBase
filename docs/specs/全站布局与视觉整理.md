# 全站布局与视觉整理

2026-10-25；版本 1.0。状态：实施规格。用户要求先由子 Agent 讨论具体方案再建设，上一批完成后以“好，进行下一轮吧”恢复本轮。建设方在既定蓝白柔黄、学术实用、少小字的授权内决定界面方案与施工拆分；本轮不改变 [产品规则](../../PRODUCT.md) 或 [术语](../../GLOSSARY.md)。

## Problem Statement

各页面先后建设，虽已统一配色，但导航、字号、查询区、卡片、长详情和维护动作尚未形成一致结构。资料库常驻筛选占据首屏，中屏阅读双栏偏窄；窄屏只剩图标导航，来源与专题长详情难定位。研究员需要先看到材料、读清内容、找到下一步操作。

## Solution

统一全站页面骨架、文字和操作层级。保留熟悉的业务入口；桌面用有分组的文字导航，窄屏用可展开的文字菜单。查找页面收拢低频筛选与整理动作，已用条件始终可见。来源、人物、专题详情按内容和关系分节，提供章节跳转；公共样式在唯一基础层维护，领域样式只处理自身布局。

## User Stories

1. 作为成员，我希望各页使用一致的标题、搜索、结果与操作顺序，以便换页后仍能快速定位。
2. 作为窄屏用户，我希望打开有文字的导航并知道当前页面，以便不用猜图标。
3. 作为键盘用户，我希望菜单可关闭、焦点合理恢复，以便继续操作而不陷入隐藏区域。
4. 作为研究员，我希望查找页首屏尽早出现实际条目，以便打开平台即可开始阅读。
5. 作为研究员，我希望按需展开筛选，并始终看见已经应用的条件，以免误解搜索范围。
6. 作为研究员，我希望资料库、成果、收藏和待核对页保持各自固定范围，以免重置筛选改变页面含义。
7. 作为研究员，我希望长题名、原名、日期、出处、必要状态有清楚层级，以便比较材料且保留真实信息。
8. 作为研究员，我希望明确选择后才突出批量操作，并看到数量与范围，以便减少无效按钮干扰。
9. 作为研究员，我希望宽屏连续阅读有足够正文空间，中窄屏可专注阅读并返回原位置，以便不中断查找。
10. 作为成员，我希望在来源目录清楚区分类型、主办国别与国际定位，以便准确查找来源。
11. 作为成员，我希望来源详情能快速定位介绍、译稿及资料、关联与依据，以便持续整理和使用内容。
12. 作为成员，我希望人物档案清楚呈现介绍、任职、作品和研究笔记，身份整理动作有明确入口，以便阅读不被低频操作挤占。
13. 作为研究员，我希望工作台的搜索与真实续作入口清楚可见，以便接续已有工作。
14. 作为研究员，我希望专题卡片简洁，详情能在研究问题、成果与材料之间定位，以便不必翻过长笔记才能找到资料。
15. 作为成员，我希望草稿有清楚的题名、类型、时间与继续入口，以便准确恢复自己的编辑。
16. 作为管理员，我希望账号、导出、备份和采集入口分组清楚，运行能力说明准确，以便判断操作后果。
17. 作为编辑者，我希望表单、保存、历史和比较窗口清楚可读，以便维护复杂资料而不遗漏必要字段。
18. 作为编辑者，我希望作者授权、保存冲突、失败保稿与身份依据继续明显，以便界面简化不削弱内容责任。
19. 作为成员，我希望长链接、表格、空列表和缺图条目在手机及放大显示时仍可使用，以便不同屏幕都能完成工作。
20. 作为成员，我希望颜色服务导航与状态，必要文字字号正常且对比足够，以便长时间使用不刺眼。

## Implementation Decisions

- 沿用现有技术、路由、数据模型及权限接口。本轮范围覆盖登录、全站导航、工作台、资料及固定视图、来源、人物、专题、草稿、维护，及共用阅读／编辑／历史／比较窗口。不重写业务组件或引入外部字体、框架和 CDN。
- 使用现有深蓝、白与浅灰为主体，柔黄用于少量强调和待核对背景；黄色不用作普通正文或白字按钮。颜色之外保留状态文字、形状与焦点。保留现有平台标识，不使用未经确认的校徽或官方认证。
- 统一排版角色：正文约 16px，长文约 17px，必要元数据、标签及说明至少 14px；主标题约 28px、窄屏约 24px。同类控件、圆角、内距、边框及分组间距一致。主要正文以白底深字呈现，宽表格在局部容器滚动。
- 基础样式、公共控件与页面骨架明确归属，梳理实际加载顺序并消除已有冲突；领域样式保留必要的局部布局。现有离线阅读与导出样式保持独立可用，不再加无边界的总覆盖层。
- 保留导航名称、业务分组和当前项状态；窄屏收起常驻图标栏，提供有标签的开关及完整文字导航。打开、关闭、Escape、选中页面、返回焦点和切换视口均有确定行为。隐藏导航不留可聚焦的幽灵控件。
- 查找页面统一页头、检索、可展开筛选、已应用条件、结果工具和内容顺序。一般高级筛选默认收起，条件应用后仍可看见和清除；保留成果／待核对等固有范围。来源国别与国际属性分别表达，不删除必要解释。
- 资料列表沿用紧凑／卡片切换、显式跨页选择与连续阅读。未选择时收敛批量动作；选择后提供既有操作。宽屏双栏按足够可用宽度启用，中窄屏使用可返回阅读；样式断点与阅读的语义角色、焦点及滚动行为共同调整。检索、页码、选择、滚动、焦点、迟到请求及账号清理语义保持。
- 来源与人物卡片统一题名、原名、状态和主入口层级。来源介绍与来源内容已前置，继续保留；增加真实章节标题与节内跳转，按已有内容形成概况、资料／译稿、关系和依据等分组。人物维持整页档案，身份纠错与历史为清楚的次级整理入口。跳转不改应用 hash 路由。
- 工作台保留搜索与真实草稿／专题／本人成果续作，统计次要；专题保留研究问题，增加研究内容／成果／资料定位，取消无意义固定卡片高度；草稿不重复浏览器归属说明。维护页按成员、导出备份、采集入口和运行说明分组，权限、完整备份后果保持明显。
- 删去装饰眉题、口号和重复空态说明；保留原名、出处、未知状态、作者责任、权限、版本、冲突、恢复与备份后果。纠正仍称附件文字提取未开启的旧文案：当前支持可提取文字的本地附件检索，OCR、自动采集和正式网络部署未包含。
- 施工拆成三个可独立演示的流程：①导航／查找／阅读及公共视觉；②来源／人物浏览与详情组织，依赖①；③工作台／专题／草稿／维护，依赖①。公共文件由单一任务拥有，后两项在同一基础上分别建设再集成。具体任务状态由 GitHub 维护。

## Testing Decisions

沿用此前已确认的应用 HTTP、公开下载、恢复与实际页面操作边界；不引入新的内部测试界面。纯视觉用截图和真实计算样式核查，不写样式实现镜像测试。新增导航、筛选展开和章节跳转行为按 TDD 通过真实浏览器验证；数据全部使用独立临时库及合成样本。

1. 同一合成样本保留桌面前后截图：工作台、资料列表及阅读、来源目录及详情、作者档案、编辑窗口。其余页面全站走查，说明可见结构变化；截图本身不证明权限正确。
2. 覆盖 1440／1366、1024／901、768、503、390、320px 与 200% 缩放。验证菜单文字可达、列表首屏可见实际条目、阅读正文空间、关闭与返回位置。全页不横向溢出，宽表格可局部滚动。
3. 实际键盘完成菜单、搜索、筛选、阅读、章节定位和编辑取消，校验 Escape 与焦点；收起区域不截获焦点。长文／长题名／长 URL／多标签／无头像／空列表纳入样本。
4. 保留列表视图、分页、选择、批量动作、附件命中位置、来源多维筛选、人物返回及身份整理入口。运行现有阅读和批量浏览器检查；测试中随新交互显式展开菜单，不以直改隐藏状态代替操作。
5. 实际验证草稿续作、版本冲突保留输入、作者授权提示、历史／比较／恢复入口、专题关联、不同角色的维护入口；复用现有 HTTP 权限及版本验证。正文及离线导出表格仍可读。
6. 核查实际前景／背景对比，普通文字目标至少 4.5:1；必要辅助字至少 14px。无新增页面脚本错误和外部字体请求。最终运行项目完整检查及双系统 CI，双轴独立审查后处置问题。
7. 本机切换前完整备份；只读比对真实表内容和原附件，确认不因界面交付导入或改写研究数据。开发自测、独立验收、历史证据及实际部署分别记录。

## Out of Scope

来源采集、自动翻译、OCR、研究评价、权限重设、数据清洗、真实资料合并、新导航业务对象、实时协作、富文本编辑器替换、正式多人部署及完整品牌 VI。全站整理覆盖本规格的页面与公共组件，不代表所有未来使用场景已完成研究员试用。
