## 已确认的行为

- 机构、期刊和单篇资料分别理解；机构类型与机构关系分开。符合条件的子机构只登记一次，不同入口访问同一编号。
- 期刊按主办方国家归类，出版方国家另记；多国主办可多国归类。缺失、冲突保持待确认，显示所据的主办关系和国家信息。
- 主办指有依据的办刊机构归属或学术组织责任，不要求法律所有权或创办者审计。既有登记可使用并标明上游依据层级；少量官网样本未再次验证某项，不等于全部旧登记失效。上游明确角色待核或实际冲突时才标待确认。
- 国际定位独立为是、否、未知；是或否均需依据，未知不能按否处理。
- 隶属、联合设立、合作、资助分别表达，关系须有证据。期刊主办关系不推导机构隶属。
- 详情和编辑只展示适用字段。机构不显示 ISSN、期刊主办方等占位项。

## 本轮选定的可调整方案

- 指挥方选定机构、期刊、其他出版物三个主要入口（另有全部）；年鉴和工作论文系列归其他出版物。门户移至数据与维护。旧来源表出版物仍以原 ID 保存在其他出版物，核清前不合并或删除。这是本轮界面方案，不是永久产品条款。
- 保留现有 sources 编号及旧字段，在同一记录上增加机构类型标签、国别与主办关系依据、国际定位及其依据、带方向的机构关系。旧分类和原始备注折叠显示。
- 类型按机构自身身份生成，不从大学归属描述继承大学标签；明确的高等教育与研究职能允许多标签。历史高校保留高校类型及历史状态，不声称现为独立大学；明确名称中的智库身份进入新导入默认值。对本轮自动标签的纠正仅处理历史可证明未被人工修改的记录，备份并形成新版本。
- 机构关系由起点记录维护，作为该来源版本快照的一部分；反向浏览即时读取关联，编辑反向关系时回到起点。隶属为下属→上级，联合设立为被设立机构→设立方，资助为受资助方→资助方；合作双向展示，避免反向重复登记。
- 国别按已登记主办关系及机构国家动态生成，不回填旧期刊 country。每项结果显示依据；不完整关系或有争议的主办角色进入待确认。信息来自上游登记时明确其核查层级，不将它标为中心已核对。
- 关系与来源修改在同一写事务内校验，拒绝自关联、重复、无效对象和隶属循环。恢复历史也重新校验；旧快照没有新增字段时保留当前新增字段，避免历史结构缺项意外清空资料。
- 切换主要类型清除不适用筛选；修改机构国家或主办方时，未同步更新的原依据失效并转待确认，原依据仍在历史。普通编辑保留 classification 原值，不用显示标签覆盖机器分类。
- 既有来源的对象类型可纠错，稳定编号不变；同类适用字段继续保留，表单来回切换保留尚未提交的填写内容。转换后不适用字段从当前记录移出，但旧值保留在历史。机构尚有自己维护的关系时先处理关系；被其他机构或刊物引用时服务端明确阻止转换，历史恢复遵守相同约束。
- 增量迁移前生成完整备份；只增加字段与对应版本记录，保留原 ID、资料、收藏、专题、附件和历史。支持旧备份升级及新备份完整恢复，不全库重导。

沿用项目此前核查的 [Zotero 条目类型与字段](https://www.zotero.org/support/kb/item_types_and_fields) 和 [Omeka S 资源模板](https://omeka.org/s/docs/user-manual/content/resource-template/)：借鉴对象类型决定适用字段、同一对象保持身份的做法。只用于字段和界面组织，不引入其系统或新增依赖。本轮在线复核未及时返回，未据此宣称新增版本特性。

## 验收场景

1. 三个主要入口及机构类型筛选可用；门户在维护区可管理，旧编号和引用保持可访问。
2. 真实期刊按有依据的主办国家可筛选；多国主办、出版方国家独立、缺失／冲突和国际定位三态在隔离样本中组合验证。
3. 机构详情和表单无 ISSN 等不适用字段；期刊可查看和编辑适用信息、依据与国际定位。
4. LV PEAK 可从大学、学院及智库筛选抵达同一记录；BICEPS/SSE Riga 显示合作。关系可编辑、双向浏览，并拦截循环、自关联、重复及无效目标。
5. 版本冲突、历史恢复、迁移幂等及备份恢复通过；既有数据和人工修改保留，恢复不绕过关系约束。
6. 原有回归测试通过；实际本地浏览器走过筛选、不同对象详情、关系跳转、编辑与恢复。验证结果单列于执行记录。
