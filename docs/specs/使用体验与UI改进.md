# 使用体验与 UI 改进

2026-10-23；状态：已实现并完成本轮独立验收，8848 已加载新版。指挥 Agent 负责范围及独立验收；具体证据和边界见 [验收记录](../../work/使用体验独立验收.md)。

## 目标及依据

让研究员更顺畅地找到资料、打开原文、留下阅读记录、继续专题和带出处复用。保留蓝、白、柔黄的学术风格；减少口号、重复说明和过密小字。沿用 [PRODUCT](../../PRODUCT.md)、[研究资料工作流程](研究资料工作流程.md) 的对象、权限、共编与固定引用规则。

本地观察：工作台统计占据首屏；列表不能直接阅读；详情编辑按钮先于阅读；已有草稿、摘录、专题及版本保护可复用。导入外部资料只有题录和链接，外部文件线索不等于平台已保存全文。

官方参考与本项目取舍：

- [Zotero 阅读与笔记](https://www.zotero.org/support/pdf_reader)：标注加入笔记时保留出处和返回原文位置。借鉴记录与原文紧邻、引用可追溯；本轮不建设 PDF 标注器。
- [Zotero Quick Copy](https://www.zotero.org/support/creating_bibliographies)：减少从条目复制引文到写作工具的步骤。先提供清晰的纯文本出处／摘录／引用清单，不声称符合特定论文引用标准。
- [PubMed 使用指南](https://pubmed.ncbi.nlm.nih.gov/help/)：区分检索结果、摘要和外部全文入口，明确已应用的筛选。借鉴阅读入口与筛选反馈，不复制医学检索体系。

## 本轮交付

1. **工作台继续研究。** 搜索保留首要位置；当前账号本机草稿、近期专题、本人近期成果的继续入口前置。使用真实更新时间，不虚构“最近阅读”或完成进度。统计压缩为次要信息；空状态给出可操作入口，不展示虚构内容。
2. **资料列表直接阅读。** 每条资料保留易读的题名、作者、日期、语种和摘要／命中片段；按实际信息提供原文网页、官方文件链接、平台附件或网页正文入口。标签必须表达真实保存状态；无需逐条额外请求。搜索后的筛选条件可看见并清除；关闭详情后保留检索、分页和滚动位置。原文外链新标签打开。
3. **详情围绕阅读。** 标题和核心出处之后先提供阅读操作，编辑、历史和核对放次级位置。原文网页、外部官方文件和平台附件分别表达；只在有内容时展示相应区域。正文、摘要、摘录与阅读说明层次清楚；辅助字段可折叠，不能隐藏重要版本／权限／冲突提示。
4. **写阅读说明。** 原始资料详情增加便捷入口，复用普通研究笔记，并通过原文关联连接该资料。可写为何值得读、局限或研究用途；默认可不填写，不新增强制字段。显示作者及时间，明确是研究员记录，不混入原始摘要。个人作者授权规则不变；正式“摘录”仍须原文和定位，不能借入口放松要求。
5. **带出处复制。** 原始资料可复制题录出处；摘录可复制原文、译文、研究说明、位置和所据原文版本；报告／编译成果可复制其引用清单。依据为报告采用的快照，不悄悄改成笔记最新版本；受当前可见权限约束。复制失败时提供手动选择文本，不只显示失败提示。按钮说明复制内容，不制造正式引文格式承诺。
6. **可读性与适配。** 保持当前品牌方向，控制按钮数量和灰色小字，表格／长标题／长网址合理换行；桌面和约 390px 窄屏可用。键盘可到达主要操作，焦点可见，说明与输入有明确对应。

[接口约定](../../work/使用体验接口契约.md) 是本轮前后端协作依据。建设 Agent 独占后端、测试及其执行记录；采集 Agent 承担前端，独占 static/、templates/ 及其执行记录。指挥 Agent 维护本规格、任务计划及独立验收，两个执行方均不得并发改写对方文件。

## 边界与验收

不改变对象模型、目录共编和作者授权，不进行真实数据批量改写、自动采集、附件全文提取、实时协作或正式联网部署。ThinkTank 只读。复制文字不能泄露隐藏记录或已失去访问权的引用；链接清洗只检查合法地址，不代表已验证可达。

使用隔离数据完成：从搜索打开原文／附件、写阅读说明并从原文返回、草稿续作、专题续作、出处复制、旧引用版本保持、不可见引用不泄露、窄屏操作与长内容展示。保留现有来源国别筛选、内容编辑／冲突、专题和权限回归。正式库只读前后核对，独立验收与执行方自测分别记录；真实研究员试用尚未实施。
