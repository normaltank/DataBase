# 期刊档案与按期编译

版本：1.0；日期：2026-10-27。状态：按用户确认方向形成的数据与行为设计，尚未施工。授权与样例检查出处见 [R020](../需求讨论记录.md#r020期刊编译模板与首批来源采集)。本规格沿用 [PRODUCT](../../PRODUCT.md) 的身份、国别、共编与研究质量规则；实施状态由 GitHub Issues 维护。

## Problem Statement

研究员需要持续维护期刊背景，按期阅读原文目次与中文主要内容，并把这些积累用于后续研究。现有期刊档案和自由正文目录译稿能够存放介绍及编译，但创刊、发行周期、分年度指标、独立卷期和有序目次尚不能贯通维护。将全部内容写成一段简介，难以按年比较指标、定位某期或复用同一篇文章；把每份编译强制拆成文章，又会阻碍已有跨期目录译稿。

## Solution

沿用一个期刊档案，组织期刊基本信息、分年度指标、各卷期目次及关联的中文编译。读者从期刊进入某期，先浏览目次，再阅读选编内容或原文；研究员可以只登记已知信息，逐步补齐，整体目录译稿继续可用。

数据关系为：期刊拥有卷期，卷期拥有按栏目和顺序排列的目次条目；条目可以关联一份已入库资料，未入库时保留出处。目录译稿关联一个或多个卷期／覆盖范围，并对其中部分或全部条目保留中文编译。一篇资料仍只有一个稳定身份，可以被多份编译或研究成果引用。

## User Stories

1. 作为研究员，我希望维护期刊原名、中文名、创刊时间、周期、聚焦领域、ISSN、出版机构及官网，使同事能准确了解该刊。
2. 作为读者，我希望看到期刊封面，并知道它属于当前卷期还是示意图，避免把旧图片当作当期信息。
3. 作为维护者，我希望分别维护纸本和电子 ISSN，保留旧的未分类标识，避免拆分时丢失原值。
4. 作为研究员，我希望按年度查看普通影响因子及五年影响因子，知道指标名称、年度和出处，避免跨口径比较。
5. 作为维护者，我希望分别保存每个大类、小类学科的分区及所属版本，避免把“2/3 区”存成无法解释的单一数值。
6. 作为研究员，我希望登记某个卷期的出版标识和原目次出处，允许年份、卷号、期号尚不完整。
7. 作为读者，我希望目次保留原顺序与研究文章、书评等栏目，并能看出是完整目次、部分收录还是尚未核实覆盖范围。
8. 作为贡献者，我希望先录入题名、署名和链接，之后关联文章，不因缺少 DOI、作者档案或全文而无法保存目次。
9. 作为编译者，我希望选择目次中的部分文章写中文主要内容，也能先保存整份跨期译稿，逐步建立对应关系。
10. 作为读者，我希望区分原文摘要、摘要译文与编者概述，能追到所依据的原文或样稿版本。
11. 作为维护者，我希望一篇文章被多处引用时沿用原有记录，作者身份仍有单独的核对过程。
12. 作为成员，我希望目录译稿及公共档案继续共编，个人编译报告保持作者授权，冲突时当前输入得到保留。
13. 作为复用者，我希望导出与备份恢复后仍能还原指标出处、目次顺序、原译关系、附件及旧版本。
14. 作为老数据使用者，我希望已有期刊、文章和跨期目录译稿继续可读可编辑，不因新增结构被强制改名、拆分或重新授权。

## Implementation Decisions

### 期刊档案与封面

- 复用既有期刊身份。原名、中文名、别名、介绍、研究覆盖范围、官网、主办与出版关系继续沿用；新增创刊时间、发行周期、纸本 ISSN 与电子 ISSN 的适用表达。时间保留实际精度，未知项可空；周期允许说明和有依据的变更。
- 原有 ISSN 原值保留，不按先后位置猜测媒介类型；核实后再归入纸本或电子标识。期刊字段只出现在适用对象，机构表单不增加占位项。
- 封面是带出处的图片或附件引用，标明所属期刊、可选卷期、说明及示意用途。期刊档案可以展示通用封面，卷期可以指定本期封面；复用旧封面时明确提示。外部图片线索与已保存文件分别表达，保存及访问沿用附件授权。
- 出版机构与主办机构分别保存；出版集团名称可保留原始写法，是否关联机构档案依据核对结果。出版方不能覆盖期刊国别。

### 按年度／版本保存指标

- 每条影响因子记录含指标名称（普通／五年或原始口径）、数值、指标年度、出处与核对说明；资料另列发布年份时分别保留。缺失年度或含义不明时展示原始标注及待核实状态，不猜填当年。
- 中科院分区按年度／版本组织，每个学科条目分别记录大类或小类、学科原名及中文名、分区和依据。一份版本可以有多个小类及各自分区；学科不固定为社会学或政治学。
- SSCI 等收录信息与中科院分区分别表达；“SSCI 2 区”等原始混合文字保留为来源表述，未核实前不自动推导为某个学科的正式分区。指标不形成平台综合影响力得分，也不代替政策／社会影响证据。
- 新年度增加记录，保留旧年度。对同年度错误的纠正仍保留修改历史和原始依据；缺失值与数值零分别显示。只有可比较口径才并列比较，默认显示的最近已知记录明确其年度，不暗示当前年度已核实。

### 卷期与目次

- 卷期引用同一期刊，保存出版年份、原卷期标识、可选出版日期、专刊／合刊说明、原目次出处及封面。中心概览的编译时间、发布日期和原刊出版时间分别保存；未确定卷期时保留覆盖范围，不从封面、文章日期或文件名强建卷期。
- 目次包含有序栏目和有序条目。条目可保存原文题名、中文译题、原始署名、DOI／原文地址、页码／文章编号，以及可选的资料关联。研究文章、书评、社论等类型保留原刊表达；书评不等于所评图书本身。
- 同一条目后来关联资料时，使用既有重复核对及身份选择流程。条目属于某一期的有依据关系，与文章原有卷期题录互相核对；冲突保留输入并提示，不静默改写文章或改期。
- 明确显示目次覆盖范围（完整／部分／未核实）、所据目录及核对时间；“完整”需有原目录依据。目次条目没有摘要、未入库或没有本地全文均为正常状态，不能据此删除或标为无价值。

### 编译内容与原文关联

- 复用目录译稿及现有成果身份，不仅因采用模板就建立新的个人报告类型。按期概览可连接一期或多期，已有跨期覆盖说明继续保留；结构化条目是逐步补齐能力，整体富文本仍可编辑。
- 目次与主要内容分别组织。编译者可选择条目编写中文内容，明确摘要译文、编者概述或来源未核实的摘编；保留所据原文、来源版本／定位、编译者及修订历史。没有原文摘要时，不将中文概述标成原文摘要的译文。
- 原文题名、原始署名及文章单位保留；中文译名与确认的人物身份分别处理。目次录入和编译不会自动建立已确认人物或任职关系。
- 同一文章被不同译稿使用时，引用同一资料身份并保留各自采用的内容版本。原文或公共资料后续变更时提示复核，旧编译依据不被悄然替换。
- 编译、审校等署名角色与账号授权分别表达。目录译稿走既有共编规则；明确登记为个人报告的编译成果走作者授权规则，不根据 PDF 署名或是否有摘要猜测权限类别。

### 使用与兼容

- 期刊页以封面和简洁基本信息、年度指标、卷期目录及编译内容组织；保持克制蓝白黄、中文优先、原文可追溯，编辑时先显示常用信息，缺项允许后补。
- 主动检查从期刊查找、卷期浏览、目次到文章、返回原位置、编译与历史的完整路径，兼顾桌面和窄屏。新字段进入既有可读导出和完整备份，附件沿用可见范围。
- 增量迁移保留旧编号、自由文本、关系、权限和历史。旧文章的卷期文字仅为线索，未经核对不自动创建或合并卷期。旧目录译稿不批量拆分成文章。

## Testing Decisions

沿用既有公开 HTTP、实际浏览器及新目录备份恢复边界。只断言用户可观察的保存、读取、修订、引用和权限结果；测试实现结构不作为完成依据。

1. 用独立合成期刊覆盖普通／五年影响因子、跨年版本、一个大类多个小类、未知年度、零值和混合原始标注，核查保存、历史、导出及恢复一致。
2. 用两期、合刊及跨期译稿覆盖完整／部分目次、栏目顺序、未入库条目、仅有书评题名、部分主要内容、同文多处复用与卷期冲突。
3. 在 1366px 和 390px 完成期刊→卷期→目次→文章→返回→编译保存→另一成员修订→冲突保稿的完整路径；分别核查普通成员、不可读者和个人报告未授权者。
4. 用旧版本隔离库迁移、完整备份恢复与可读导出验证稳定身份、原文／译文版本、指标出处和封面附件。旧 ISSN、卷期文本和跨期正文不丢失、不被自动确认。
5. 两份用户样例只用于本地核对结构覆盖，不提交 PDF 或全文。材料核验另记录原始来源、覆盖范围、处理方式与独立对照证据；模板展示了某个数字，不等于该数字已获官方验证。软件验收不证明期刊评价或文章研究结论可靠。

## Out of Scope

自动将两份 PDF 导入正式库、自动生成排版 PDF／Word、批量抓取期刊指标、获取付费全文、自动确认身份、自动打分、全面研究看板，以及把全部目次强制变成单篇资料。

首批拉脱维亚来源发现按 #46 的独立范围推进；它不能以本规格为依据扩张为采集这两本样例期刊或自动取得全部全文。
