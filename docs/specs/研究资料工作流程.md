# 研究资料工作流程增量建设

制定日期：2026-10-22；验收日期：2026-10-23。状态：A → B → C 本地流程已实现并完成本轮验收。本文件定义本轮本地可用版本，不代表正式联网部署或甲方合同验收。实现记录与验证证据见文末，指挥方计划在 `.planning/2026-10-22-research-workflow/`。

## 授权与依据

用户先确认 R005 的分份归档、网页编辑加附件、目录译稿全员共编、普通共编加冲突保稿；在指挥方提出七项建议与顺序后回复：“可以，按你说的去做吧。”此回复撤销本轮尚未开工状态，允许依下述次序建设。产品长期规则见 [PRODUCT](../../PRODUCT.md)，讨论出处见 [R005](../需求讨论记录.md#r005来源详情中的可编辑内容与目录译稿)。

## A：来源内容与共编检索

1. 机构、期刊、其他来源详情都能维护介绍，查看关联内容并从该页新建目录译稿。正文、元数据、原目录出处与附件清楚分开。内容只有一份实体，来源页、资料库、专题及检索访问同一记录。
2. 目录译稿逐份保存，填写题名、编译者以及年份/卷期或覆盖范围；可跨期且不要求拆为单篇文章。不把关联来源自动当发布方，允许实际需要的一般内容关联。
3. 网页编辑包含标题、段落、列表、表格和链接。技术形式由建设方选择，但应让非技术成员直接完成编辑；不要要求使用者写代码或了解存储格式。支持现有 Word/PDF 附件，网页正文与文件各自保留，不在线改写附件。
4. 所有有效中心成员可编辑目录译稿与来源介绍；个人成果权限不得因此变成全员可改。译者、上传者和修改者分别保留。
5. 并发保存发现版本变化时保留当前输入，明确给出查看新版本和继续处理的途径；不能通过刷新/关闭编辑器丢弃草稿，也不能静默覆盖。新正文、来源关联及附件引用进入历史，可恢复。
6. 新正文和介绍纳入检索，结果显示安全呈现的命中片段。沿用现有筛选；中文/原文/别名搜索一致。不宣称已有附件全文或任意语言语义检索。

## B：身份整理与研究摘录

1. 来源和资料支持别名或其他题名，搜索可命中。旧名称和编号保留可追溯线索，不凭推测建立机构更名关系。
2. 提供疑似重复提示和人工比较确认合并的能力。合并前显示影响；稳定编号、附件、历史、收藏、专题、原文引用及来源关系不丢失。处理循环、错误对象类型、权限及可见范围冲突，遇到不能安全合并的情况明确阻止。合并行为保留审计与原记录线索。真实库不自动合并；验收仅用隔离数据。
3. 在原始资料下保存带出处的摘录，至少包含原文摘录、自己的译文或说明、页码/段落/其他定位、链接或附件及引用时资料版本。原文与研究员解释分开，可从摘录返回对应资料和可用原文位置。
4. 摘录/笔记可被专题和报告引用，引用不复制成另一个不可同步的独立正文；同时保留引用所据版本或快照，避免原文更新后旧报告的依据悄然改变。尊重已有可见范围。

## C：专题研究、成员与保存

1. 在既有专题上补研究问题、比较笔记和阶段判断；能把资料和证据放入专题，编写报告并引用证据返回原文。支持成员手工整理，先完成朴素可用流程，不建设自动分析或生成结论。
2. 个人笔记/报告按作者授权规则维护；中心专题与个人专题沿用原有可见边界。2026-10-22 用户 Grill 已确认：本人提交直接生效，代交时指定负责作者并由其确认；正文仅作者及授权同事可改，管理员未经作者授权也不能改写或恢复个人正文。目录译稿仍全员共编。上传者、负责作者和署名分别保留；既有报告不能因历史提交身份自动视为作者已确认，使用明确确认和审计完成衔接。
3. 本机提供真实成员的创建、停用和必要凭据管理能力，停用不删除署名及历史；保护最后一个有效管理员。正式账号名单、运行位置、联网与部署不由开发者代为决定。
4. 新正文、附件、关系、摘录、专题和历史全部进入完整备份；恢复工具兼容新结构，实际演练恢复到新目录。提供完整、可阅读/交换的内容导出，不只标题清单；导出沿用读取权限，不泄露不可见内容或账户凭据。
5. 给出本地可执行备份与维护方式。定时独立备份存放位置与正式排程在运行安排明确后配置，本轮不擅自设置跨项目系统任务或外部服务。

## 数据、界面与工程边界

- 增量迁移前备份，保留旧编号、修订与用户数据。ThinkTank 始终只读，不批量搬运历史个人附件。测试数据置于隔离目录。
- 延续已交付的蓝、白、柔和黄主题及简洁文案。主要文字清晰可读，桌面和窄屏都能完成编辑。说明出现在需要的位置，避免新增口号、密集小字或无用指标。
- 优先复用既有 Flask/SQLite、记录、关系、附件、修订与权限机制；新增正文安全处理，链接允许安全协议，普通成员不能通过字段绕过权限。
- 可以为本轮增加必要依赖，但不需要更换平台或连接外部收费服务。实现细节由建设方决定；新核心业务分歧由指挥方澄清。
- 附件全文提取、OCR、自动采集、自动翻译、实时协同、正式网络部署及高级分析是后续按需求扩展的事项；不影响本轮上述可用流程交付。

## 验收路径

在隔离样本完成：从期刊新建一期目录译稿 → 添加正文表格和附件 → 不同成员修订 → 模拟保存冲突保留输入 → 通过正文和别名查回同一份内容 → 选取原文记录并保存带页码摘录 → 加入有研究问题的专题 → 编写含证据关联的报告 → 从报告返回证据及原文 → 导出 → 备份恢复后验证正文、文件、关系及版本仍可用。

另行验证：机构及其他来源相同入口；个人/受限内容权限；重复合并后旧编号、专题、引用和历史；旧数据库迁移完整性；成员停用及最后管理员保护；已有国别/国际期刊筛选、机构适用字段和主题无回归。只运行与新增行为相关且能验证真实规则的检查。
