# 期刊成果归档与三刊公开采集

版本1.0，2026-11-04。状态：用户已确认业务范围，待施工与验收。决定出处见[R030](../需求讨论记录.md#r030期刊成果归档与三刊公开采集)。当前实现和交付以GitHub对应任务及最终提交检查为准；旧期刊档案、年度指标及完整原刊目次设计仍保留原范围。

## Problem Statement

中心已有整期概览PDF，需要持续保存、查找和复用。现有入口要求先建立“期刊工作”、选择稿件类型，再另行采用为成品；直接导入的成果又不易在默认主列表找到。单线文件版本无法准确表达一期并列的多个文件。这些步骤不符合当前仅保存中心成果的实际需要。

研究员还需要及时发现所关注期刊的新文章，把外部资料积累与自己的编译成果接起来。只登记三个刊名，或要求开启付费AI才可运行公开采集，均不能满足本轮“真实加入自动采集，看看能采到什么”的要求。

## Solution

提供可直接进入的“期刊成果”入口，按刊名、年份和成果期次查找。成员一次登记已知期次并上传整期文件即可保存、预览和下载；一期可有多个并列文件，每个文件仅在明确更新时生成自己的新版本。新成果由中心有效成员共同维护，记录真实操作者及历史。既有期刊工作、正文及权限保留，历史入口次要展示。

将东欧政治、巴尔干与近东研究、欧盟政治接入实际可用的公开题录入口。明确启用后由现有后台持续、有界取得题录及实际提供的摘要，进入现有资料阅读、检索、收藏和资料夹。从期刊成果可快速查找该刊文章，从已关联期刊档案可找到其成果，形成发现、积累与复用的路径。

## User Stories

1. 作为成员，我能直接找到期刊成果，而不必先建立编译工作或选择责任类型。
2. 作为上传者，我能填写刊名、年份和成果期次，直接上传已有整期PDF或Word。
3. 作为上传者，我可以使用已知刊名保存，期刊档案关联及说明稍后补充。
4. 作为成员，我能按期刊、年份、期次及文件题名查找往期，列表顺序和筛选范围清楚。
5. 作为成员，我能在一期内并列添加多个文件，添加动作不覆盖现有文件。
6. 作为修订者，我明确选择更新某份文件后才产生该文件的新版本，其他文件保持。
7. 作为读者，我默认看到各文件的当前版本，能够按需查看和下载旧版原件。
8. 作为读者，我能预览PDF及有界Word文字，下载字节与上传原件完全一致。
9. 作为共建者，我能补充或更正新成果的已知期次信息，查看真实修改人和历史。
10. 作为并发编辑者，我保存过时版本时能保留当前输入和文件，读取最新状态后继续。
11. 作为旧数据使用者，我仍可读原期刊工作、材料、正文、采用关系及其历史，旧权限保持。
12. 作为研究员，我能从已关联的期刊成果进入同刊文章，继续使用已有收藏和资料夹。
13. 作为研究员，我能从期刊档案找到已关联的期刊成果，返回后保留查找上下文。
14. 作为资料维护者，我能明确启用这三刊的公开采集，查看最近成功、真实覆盖和失败状态。
15. 作为试用者，我的AI未配置或暂停时也能持续采公开题录，且无需启用付费处理。
16. 作为读者，我能看到取得的原文题名、署名、日期、DOI和实际提供的摘要，打开原站。
17. 作为读者，我不会把缺卷期的新文章误认作某一期完整目次；一期成果也不代表所有原刊文章已编译。
18. 作为维护者，我能暂停指定来源和本机公开采集后台，阅读与文件访问仍可继续。
19. 作为数据责任者，我的人工纠正、已有确认及其他来源队列不因启用这三刊被擅自改写或执行。
20. 作为管理员，我能在完整备份、新目录恢复及可读导出后继续读取新成果、文件版本、原件及来源关系。
21. 作为手机用户，我能完成查找、打开一期、添加文件及明确更新，并返回原列表；主要操作清晰，重复核验小字不占阅读空间。
22. 作为当前便携版使用者，我能在完整备份及保全原数据后看到已授权的三份历史PDF及三刊实际取得的资料。

## Implementation Decisions

### 成果身份与期次

- 成果的刊名、年份和期次以用户明确填写及本次授权的成果标题为准，与原刊卷期分别表达。样本封面冲突不触发自动纠正、拆文或新建原刊卷期。
- 一期是中心成果的归档单元，每期可以包含多个文件系列；每个系列有不可变原件版本。相同期次再次上传应明确加入已有一期或提示复用，不静默生成难以区分的重复期次。
- 期次允许正常期号、合刊、跨期或特刊的实际标注。已知年份用于筛选排序，期次原文保留，不把自由标注强行转换为数字或原刊事实。
- 无须先建期刊档案、正文、目录、文章、负责人、审稿或采用关系。可显式关联已有期刊来源，关系用于同刊资料与成果互查。
- 新成果按中心共享与共管处理，编译署名与上传/修改身份分别理解；不从PDF署名猜成员账号。旧个人报告和旧共编目录权限分别保留，不批量转换。

### 直接保存、版本与阅读

- 后端以小接口集中完成“保存一期成果”“添加并列文件”“明确更新文件”及读取历史，复用既有认证、文件检查和原件存储。实际行为及数据变化在同一事务边界提交；失败不会留下半期次或孤立文件。
- 更新保留真实文件系列、操作者、时间及旧原件；重复请求可识别，过时状态不覆盖新内容。常驻UI只展示任务所需信息，失败恢复才显示相关说明。
- 预览是阅读便利，不改原件。PDF可在浏览器查看，Word以实际可提取的有界文字预览；版式依原件，不建设在线Office编辑器。
- 完整备份与严格恢复校验覆盖新增关系和历史，旧档案及其固定采用仍按原语义验证。可读导出包含所选成果的元数据、全部声明文件版本与原件；元数据与原件保持可独立核对。
- 沿用现有蓝白操作型工作台，将上传、查找、预览和下载置于主层级。原期刊工作入口收在次级历史区；正常阅读删除重复免责声明和核验自证。

### 三刊公开采集与研究复用

- 固定刊物身份：East European Politics（2159-9165 / 2159-9173）；Journal of Balkan and Near Eastern Studies（1944-8953 / 1944-8961）；European Union Politics（1465-1165 / 1741-2757）。官方站与本轮取得依据见[真实核查](../../work/三刊公开题录采集核查.md)。
- 采用真实可达的Crossref期刊公开JSON题录入口，保留取得时间、实际响应依据、来源与稳定DOI。直接保存已取得题录，不以出版社HTML成功为先决条件。摘要只有响应实际提供时才保存；无卷期不猜配，题录不冒称全文。
- 使用现有持久采集队列、水位、去重、续作与人工字段保护。每轮请求/条数/时间有界，记录实际覆盖窗口；增量推进避免仅按最近发表时间遗漏后补元数据。完整历史回填、上游撤回体系和整期完整目次不在本轮范围。
- 便携公开采集有独立的本机显式许可和来源名单。AI未启用时只执行获许可来源的公开采集，保留AI凭据清除、暂停和统一费用边界；不顺手执行旧中文/档案队列或名单外旧来源任务。新增资料按既有规则可登记后续候选，排队与实际执行分别记录。
- 共享发行默认关闭后台；当前副本由本次授权明确启用三刊。停止/暂停与重启沿用原生命周期，机器许可不随业务备份恢复到别处后自行开启。已有AI明确启用时的行为与账本不被重置。
- 从本刊文章进入现有资料阅读、收藏和资料夹，使用既有文章身份及权限；不另造文章副本、强制选题或强制成果匹配。

## Testing Decisions

采用已向用户说明的公开HTTP、实际浏览器及新目录完整恢复三个边界。仅验证可观察业务行为，避免将内部表结构断言作为产品验收。开发使用合成文件、模拟服务和新临时库；真实公开资料取得与现用副本操作由控制端另行留证。

1. HTTP覆盖一期多文件、文件各自版本、跨成员共管、过时保存/重复请求、错误格式/过限/失败回滚、未认证和旧私有成果边界。
2. 迁移与备份恢复覆盖旧编号/行内容/权限/原件不变，新文件归属/连续历史/散列校验及损坏拒绝。可读导出另核对声明范围和下载字节。
3. 实际前端脚本及浏览器覆盖从入口保存、查找、预览/下载、并列添加、明确更新、返回恢复和失败保稿；核查1366、900、390px及200%等效视口，不以HTTP自测代替真人界面证据。
4. 采集测试固定模拟公开JSON，验证三刊解析、缺摘要/缺卷期、重复/后补元数据、有限窗口/错误、停用、重启续作、仅名单来源与AI关闭时零付费派发。原有AI开启、暂停、停止、旧账本及备份恢复继续通过相关验证。
5. 控制端用集成后的实际采集路径每刊有界取得5条，报告HTTP与真正落库数、摘要覆盖、DOI/日期及未知项；不把研究探针成功当成应用已接通。
6. 最终集成做一次完整必要检查、独立Standards/Spec审查及原发现复核；便携/源码发行绑定同一最终源码提交并做对应原生运行检查。
7. 实际副本操作前完整备份并记录既有数据/附件/配置指纹；按授权仅导入三份PDF并启用三刊，不重播种或重置现有资料和身份。验证后保持使用者服务可用，原目录PDF不变。

## Out of Scope

期刊年度指标建设、原刊完整卷期/目次、付费全文取得、PDF/Word编辑排版、全文翻译、AI调用试验、新的提醒推送或推荐平台、自动按姓名确认作者、全历史回填、现有其他来源队列代跑、校园网络调整。

本轮不表示旧#54期刊研究档案或#66既有BJE持续更新/上游变更维护已经交付；它们保留各自尚未完成范围。真实用户PDF、账号、凭据及原始内部材料不进入公开仓库或分享发行包。

## Further Notes

用户最初强调“只储存编译成果”，随后明确要求三刊自动采集，并指出应为研究员提供微信文件之外的便利。本轮据此增加同刊文章与成果互查，以及沿用已有检索、收藏、资料夹的复用路径；未据此扩展为新的站内写作、审批或研究评价流程。
