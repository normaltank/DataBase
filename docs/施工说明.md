## 对象操作与身份接续（2026-11-10，#144 开发交接）

按 [Issue #144 v1](https://github.com/normaltank/DataBase/issues/144)在 #142 基础上扩展，操作见 [README](../README.md#对象操作与页面更新)及[便携身份说明](portable-preview.md#校园局域网临时试用)。本节仅记录开发实现；集成、独立审查、最终CI及原网站升级由父任务绑定实际提交与证据。

- 便携本机维护切换只保存此前已认证临时成员的签名会话凭据（稳定身份与凭据版本）。返回重新检查当前维护会话、回环来源、原账号活跃状态、临时成员标记及凭据版本，签发新会话／CSRF并重读权限。重复进入保留有效凭据，退出清除。普通部署无此恢复入口；旧版无返回标记时不能自动认领，既有成员密码管理与正常登录仍可恢复本人账号。
- HTML、普通脚本／CSS、地理数据、同源ESM、共享样式及ELK classic Worker使用同一内容revision。HTML与版本检查更新manifest，静态请求核对所读文件签名，发现替换时重算；旧revision拒绝，条件请求及严格CSP保持。新版client按API响应头、聚焦及定时检查给一次更新入口；模块加载失败也触发检查。更新和身份切换会检查原生及保留表单、意见、File和未知请求，未保存时阻止。搜索／筛选和未改的非空默认值不误报；页面不自动重载。
- 共用菜单从当前对象及既有adapter取得实际动作，图形只传标识、标签与回调。资料读／收藏／入夹／比较沿用原接口；材料菜单仍调用原生form，保留版本、token、request_id及未知结果原请求；历史／只读不新增权。来源／人物图节点、目录行及维护步骤复用档案、预览、修改与依据定位。菜单出滚动容器，具备触屏按钮、键盘、边缘定位、关闭回焦点及路由／账号／版本失效关闭。
- 来源、人物、工作入口继承中性主标题、类型标记、短状态及明确打开／预览；未知元数据仍在详情保存，核对、收录范围及机器来历各自表达。正文链接、地图／时间／关系／流程和39份许可保留，无新依赖、CDN或栅格资产。

## AI 自主维护首条路径（2026-11-09，#129 开发验证）

按[自主维护规格1.0](specs/AI自主维护与反馈纠错.md)，`maintenance_agent` 通过原生 Tool Calls 多轮执行公开搜索、网页取得、本地查找、正式领域保存和读回检查。维护者在“AI 自主维护”查找并选定一篇公共外部文章；后台使用同一持久 worker，保存正式作者、任职／文章单位、机构／刊物及题录字段，普通结果立即生效。旧候选及人工采用历史保留；机器操作者与 `ai_maintenance` 事件单列，不冒充人工核对，不改原件、ACL、成员署名或个人报告。文章单位和任职使用各自的版本与领域关系。

schema29 迁移前完整备份，新增任务、步骤、实际供应商材料和人物 ORCID。公开模块入口为 `enqueue(db, actor, target_type, target_id, request_id, feedback='', priority=0)`、`run_pending(data_dir, limit=1, stopping=...)` 与 `projection(db, actor, job_id)`；支持 record／person／source 目标，反馈与优先级供后续任务复用。首次运行最多24轮模型，耗尽后成员可显式继续一次，累计绝对上限48轮；每任务64步工具、8次公开搜索／取得和24次领域写入的总上限不增加。续作保留旧轮数、步骤、材料及费用，将授权人、时间、原轮数与总上限保存在schema29的settings，完整备份严格校验并随新目录恢复；普通重启不授予额外轮次。保存动作与其实际结果在同一事务中落地，完成前重新读取改动对象，未解决的写入失败阻止标记完成；所据文章变为受限或内部内容后，停止观察回放并隐藏旧记录。已发出且结果未知的请求保留费用预留，重启不自动重发。

模型与 Search／Fetch 均经统一网关；搜索和取得按成功请求各0.005元预留与结算，空搜索／明确HTTP失败记零，未知响应保留占用。已结束且账本明确为固定按次Search／Fetch的未知请求，保留完整0.005元预留及原任务暂停，不自动重发；扣除全部占用后余额充足的无关任务可以继续，该类已结束请求不占在途并发。仍在发送中的请求继续占并发；模型、遗留及不能确认固定上限的未知费用保持原全局阻断。管理页原因与实际网关采用同一判定，原未知记录、账期、金额和核实入口保留。付费网页结果按实际JSON及处理后Markdown保存，与原站HTML原件分别理解；原有JSON接口保持兼容。完整备份恢复检查任务／步骤／工具观察的绑定、实际材料与费用状态。

2026-11-09统一返修补充：日常文章、人物与来源的主要AI动作直接安排自主维护，不要求先写反馈；旧候选、网页手选与采用历史收于次级旧记录入口。完成状态仅显示实际修改数量，读回与版本检查继续执行。维护页及详情状态读取核对最新读取代次，迟到结果不覆盖新结果。

长网页的完整供应商JSON、正文、原站URL、取得时间及摘要值继续存证；Search请求关闭附带全文，模型每轮接收有界的实际观察预览。`read_evidence`可按关键词定位完整材料任意位置或按字符分页；`read_field`可分页读取文本及结构字段，结构字段提供JSON格式、path和对象／集合版本，拼齐同版本所有页后才是完整关系表。大字段返回明确读取引用，不把删减后的列表伪装成完整关系；分页游标与实际发送字符一致，已发送页不会随上下文增长再次缩短。两者复用已保存数据且不再发送付费网页请求。发送前也投影旧任务中已持久的长观察，保留原生assistant／tool顺序及调用ID；原步骤、完整观察和费用记录不改写。旧任务接续发送时使用当前有效指引：有据部分及时保存，不要求穷尽所有未知项；原持久指引保留。保存结果回送省去原值与变化全文的重复，结束判断仍使用完整领域结果。约17万字符后段取证、十条正式署名完整回读后修一条、中文分页及有界续作的合成验证见[维护HTTP／worker测试](../tests/test_maintenance_agent.py)；真实供应商与升级验收仍由控制端分别记录。

## 链接与编号辅助录入（2026-10-26，#32）

[intake.py](../platform_app/intake.py) 负责 DOI 规范化、Crossref／DataCite 题录、文章标签及 Article／ScholarlyArticle 结构化信息、可见重复与已有身份／来源候选。页面只生成预览；应用后通过现有资料创建事务保存绑定成员的签名取得依据及人工核对的署名。证据使用已有 `raw_json`，不把外部题录中的发布商、单位或研究范围当作已确认主办、任职和国别。没有匹配时保留待确认署名，不自动建人物档案或合并同名。

公开网络访问限制为 HTTP／HTTPS 的 80／443 端口、至多 3 次跳转、每次响应 1 MiB、一次取得共用 15 秒截止时间，至多 4 个并发取得请求。每次跳转都校验 DNS、固定公网地址并核对连接对端，使用正常 TLS 证书验证，不运行页面脚本或附带登录凭据。慢响应头、TLS 和响应体在绝对截止时间中断，失败释放请求容量。

[public_dns.py](../platform_app/public_dns.py) 兼容本机代理的 Fake-IP DNS：系统解析至少含一个 `198.18.0.0/15` 地址，且其余结果仅属于该段或配对的 `2001:2::/48` 时，向固定 `1.1.1.1` 的 Cloudflare HTTPS DNS 查询该域名的 A 记录，再校验全部返回值并固定实际公网地址；原网址及文章内容不发给 DNS 服务。`2001:2::/48` 是 [IANA 基准测试段](https://www.iana.org/assignments/iana-ipv6-special-registry/)，这里的配对特征只触发公开 DNS 重查，不能证明整个地址段都是本机代理别名，也不授予连接许可。纯 IPv6 基准测试结果、混入其他保留／内网地址及 IP 字面值均不触发回退，绝不连接原合成地址。该路径有额外外部解析依赖，只取得 IPv4；服务不可达时保留手工录入。普通解析不走该回退，TLS、固定 IP、对端核验、逐跳安全检查和总截止时间保持，不修改用户代理设置。

2026-10-30 [#87](https://github.com/normaltank/DataBase/issues/87) 的网络修复沿用既有采集表和结构版本：HTTP 403 明确表示访问受限；429 以及带 `Retry-After` 的 503 在 LIIA 来源级保存 `coverage_json.network_backoff` 并同步 `next_run`，不覆盖既有 RSS 覆盖数据。等待值支持秒数及 HTTP 日期，缺失、无效、零或过期值用一小时，最大七天并记录 `bounded`；请求内不等待或自动重试。文章限速后保留本轮已取得的题录、失败事实和未处理条目，到期续作同一轮次；RSS 失败不生成题录，手工立即巡检／失败重跑、进程重启及重新启用均遵守截止时间。正常完成或后续其他失败清理过期退避元信息，覆盖与身份／内容依据保留。回归入口为 [DNS 兼容](../tests/test_intake_dns_compat.py)、[采集退避](../tests/test_ingestion.py)及既有 deadline／AI 公共解析安全测试；诊断、实际站检查和提交绑定证据见 #87。本轮没有 robots.txt 引擎、验证码／认证／付费墙绕过、38 站适配或持续采集启用。

前端使用紧凑题录行，替换选项只出现在已有值的字段旁。相同结果保留预览中的署名改写、身份依据、来源选择；不同结果需明确改用，既有主表单保留。账户、编辑器、输入和请求代次共同隔离迟到响应。来源取得细目折叠展示，缺项不伪造。

本轮真实样本包括一个 DOI、对应期刊页及两篇智库文章，不代表全站覆盖率。部分智库页只有题名、网址或说明；全文下载、持续采集、RSS 和任意编号解析尚未实现。

## 初始 MVP 交付

## 技术决定

- Python 3.12 + Flask 提供页面、登录和接口；SQLite 保存来源、文献、成果、关系、用户、收藏、专题及修订历史。浏览器使用原生 JavaScript/CSS，无前端编译和外部 CDN。
- 应用默认仅监听 127.0.0.1:8848；演示账号用于本机试用。本轮增补本机成员开户及凭据管理；正式联网部署、HTTPS 和运维另行实施。
- 来源、连续出版物、资料和成果保留稳定编号。机构所在地、来源研究覆盖范围、资料研究对象独立存储；没有依据的字段留空。
- 当前编辑边界按 [PRODUCT 第 3 节](../PRODUCT.md#3-已确认的共建规则)：个人编译成果及个人研究报告采用负责作者确认与授权；其余内容由可读有效成员共同修订和恢复，编辑能力不授予可见范围管理权。核对由管理员执行。编辑后回到待核对状态，保留历史。
- 个人收藏和个人专题只对本人可见；中心专题及普通提交对登录成员可见。受限资料仅提交者、授权同事和管理员可见，接口、附件和导出执行相同权限。

提交者是上传记录的账号，未必是成果作者。2026-10-22 用户确认 R004 后，负责作者账号与提交者分开：本人提交直接确认，代交待作者本人确认。当前个人报告正文及恢复只允许作者与授权同事，调整授权和范围仅作者；研究笔记共编已按 R019 更新，旧作者和确认历史保留。旧个人报告需要显式确认／认领，不从提交者或管理员身份推定。署名 authors 独立于账号、上传者和最后修改人。

生产初始化与演示分开，初始化身份持久保存，重启及模式切换不补演示成员；显式生产入口使用Waitress、精确Host与HTTPS会话，在create_app之前关闭Web内嵌档案线程。独立worker复用既有ingestion循环，以进程锁、实例标记、心跳和协作停止管理，不改变预算、租约、人工采用、内容或作者权限。管理员可在离线空内容库幂等导入65来源／56公开题录及历史机器节选。便携默认本机，显式LAN设置先替换／停用已知默认口令，启动显示实际IPv4，采用同一Waitress与仅回环认证控制，不恢复默认账号。正式操作见[服务器部署说明](server-deployment.md)，便携及LAN见[便携说明](portable-preview.md)。

新增CLI／HTTP合成测试与实际ZIP验收入口分别为 tests/test_deployment.py、scripts/check_server_release.py、scripts/check_lan_release.py；官方解释器／wheel锁、许可证和逐文件清单随发行。开发定向测试、最终全量、实际两包、双系统CI及独立双轴审查分别由本轮Issue／PR绑定提交和结果；本段不将目标机系统服务、校园跨设备互访或真实研究复核标为已验收。
