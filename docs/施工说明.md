## 研究与维护界面及轻量来源贡献（2026-10-29，#75 开发验证）

按 [#75 固定范围1.0](https://github.com/normaltank/DataBase/issues/75) 实施。研究导航保留编译协作、中心成果、资料、档案与我的；管理员另有维护导航，集中来源、数据核对、采集、中文处理与费用、账号及负责人资格、协作维护查阅、完整备份，可返回研究界面。普通成员直接访问旧管理或维护地址只显示身份说明与返回路径，不挂载管理页或发送管理员接口请求。管理员在研究界面也不显示资料／来源核对、公共重复合并及负责人资格登记等维护动作；共同编辑、个人整理、业务开期与审稿仍按既有权限使用。

来源新建统一使用“提供采集来源”短表单，编辑既有公共档案继续用完整编辑器。名称、类型、官网或目录网址构成基本输入，国家线索及推荐说明可选；期刊国家线索不参与推断主办国别。复用创建、查重、草稿、版本及修订历史，保存为候选、待核对来源；失败、重复及恢复草稿后保留输入。重复409返回既有公共来源的当前编号及名称，页面给出档案去向。维护来源默认读取全部 `status=pending` 匹配项，可查全部或已核对来源，不把旧待核对记录标成新的采集请求。

来源详情新增只读 `automatic_collection.supported/enabled` 投影，区分实际适配与管理员启用；核对与收录范围继续各自表达。当前仍仅适配 LIIA Opinions，未接入来源明确显示尚未接入持续采集。没有新增建议接受／拒绝状态机、通用采集器、身份等级或结构迁移，结构保持23；既有服务器授权保留。

开发红绿及复跑入口：

## 中心成果查找与按期材料包（2026-10-28，#73 开发验证）

[只读投影与导出模块](../platform_app/collaboration_library.py)复用当前主题、期刊及成果核权，不新增持久表或原件所有者，结构保持23。`GET /api/collaboration/works`统一业务／范围及成果投影，计数与查找仅处理当前账号可读工作。`GET /api/collaboration/materials/<topic|journal>/<id>?scope=<products|process|all>`明确选择成果、过程或全部已提交范围；具体范围见[使用说明](../README.md#中心成果查找与材料包)。旧主题过程导出复用同一成包接缝，原候选包也改为临时文件成包；逐原件分块校验、压缩，完成后重核有效账号与工作权限，失败关闭临时文件、不发送半包。包内含原名、提交版本、决定、固定采用关系及SHA-256清单，不导出其他工作、未提交文件、关联成果正文／附件或关联原文，不披露这些受限原文的身份、内容或数量。

旧独立成果与跨期译稿继续使用原身份和访问入口；旧笔记类型链接保留查询条件转到全部资料。旧正文、附件与历史继续使用原权限，关联共享成果不放开主题新原件；管理员维护查阅不取得审稿或个人报告编辑权。资格撤销、停用或参与者变化在读取、下载与导出时重核。

[独立标准库核验器](../scripts/verify_work_materials.py)不导入应用，读取ZIP逐项比对字节、路径、业务归属、版本、范围和精确采用，拒绝改写清单后仍与业务关系冲突或缺项的包。自带声明只能证明内部一致性；整份内容连同所有声明被一致恶意重造时，需要独立保存的整包SHA-256或逐原件证据鉴真，不以包内清单证明未导出内容。

## 链接与编号辅助录入（2026-10-26，#32）

[intake.py](../platform_app/intake.py) 负责 DOI 规范化、Crossref／DataCite 题录、文章标签及 Article／ScholarlyArticle 结构化信息、可见重复与已有身份／来源候选。页面只生成预览；应用后通过现有资料创建事务保存绑定成员的签名取得依据及人工核对的署名。证据使用已有 `raw_json`，不把外部题录中的发布商、单位或研究范围当作已确认主办、任职和国别。没有匹配时保留待确认署名，不自动建人物档案或合并同名。

公开网络访问限制为 HTTP／HTTPS 的 80／443 端口、至多 3 次跳转、每次响应 1 MiB、一次取得共用 15 秒截止时间，至多 4 个并发取得请求。每次跳转都校验 DNS、固定公网地址并核对连接对端，使用正常 TLS 证书验证，不运行页面脚本或附带登录凭据。慢响应头、TLS 和响应体在绝对截止时间中断，失败释放请求容量。

[public_dns.py](../platform_app/public_dns.py) 兼容本机代理的 Fake-IP DNS：仅当域名的全部系统解析结果属于 `198.18.0.0/15` 时，向固定 `1.1.1.1` 的 Cloudflare HTTPS DNS 查询该域名的 A 记录，再校验并固定实际公网地址；原网址及文章内容不发给 DNS 服务。该路径有额外外部解析依赖，只支持 IPv4；服务不可达时保留手工录入。普通解析不走该回退，本机、内部地址及直接输入的 Fake-IP 仍拒绝，不修改用户代理设置。

前端使用紧凑题录行，替换选项只出现在已有值的字段旁。相同结果保留预览中的署名改写、身份依据、来源选择；不同结果需明确改用，既有主表单保留。账户、编辑器、输入和请求代次共同隔离迟到响应。来源取得细目折叠展示，缺项不伪造。

本轮真实样本包括一个 DOI、对应期刊页及两篇智库文章，不代表全站覆盖率。部分智库页只有题名、网址或说明；全文下载、持续采集、RSS 和任意编号解析尚未实现。

## 初始 MVP 交付

在本项目中建设一个可启动、可保存数据的中文网页应用。用 ThinkTank 主资料库的真实来源和文献验证基础流程：登录 → 检索 → 看详情与出处 → 收藏/专题 → 提交资料或编译成果 → 关联原文 → 核对 → 修改历史 → 导出。

## 技术决定

- Python 3.12 + Flask 提供页面、登录和接口；SQLite 保存来源、文献、成果、关系、用户、收藏、专题及修订历史。浏览器使用原生 JavaScript/CSS，无前端编译和外部 CDN。

本任务使用合成材料在公开 HTTP、ZIP CLI、完整备份／新目录恢复及 1366px／390px 浏览器边界验证；测试见[附件锚点](../tests/test_attachment_anchor.py)及[实际页面脚本](../scripts/check_attachment_anchor_browser.py)。本段记录任务分支实现，集成、独立审查及最终放行由 [#41](https://github.com/normaltank/DataBase/issues/41)及父任务 [#47](https://github.com/normaltank/DataBase/issues/47)维护；未读取真实研究库。

## 单篇辅助翻译（2026-10-27，#49 任务分支开发验证）

按[研究资料质量与辅助整理规格 1.0 G 节](specs/研究资料质量与辅助整理.md#g-deepseek-单篇辅助翻译46-的独立子任务)提供显式单篇任务、执行、失败重试、原译对照和人工采用。机器版本独立保存输入快照、摘要 SHA-256、资料版本、出处、模型、时间、操作者及固定失败说明；人工中文字段进入共同编辑及资料修订历史。生成前后和采用时均核查当前权限。外部响应按纯文本显示；HTTP 请求有总等待、响应大小和并发边界，保留系统代理及 TLS 信任，不跟随鉴权跳转。

2026-10-28 的既存路径返修仅接受明确 `stop` 且结构有效的完成结果，其余结束状态不会作为成功译文进入默认阅读。结构18同一迁移新增逐次 `translation_calls` 依据，保留已返回的用量、请求／响应模型、结束状态、配置及价格版本快照；结构错误不丢弃已取得的用量，重试不覆盖旧执行。未知用量不记为零。默认模型改为 `deepseek-flash`，明确非thinking翻译，正式模型及价格通过运行环境配置；无配置价格时保持未知。运行说明及现行官方资料见 [README](../README.md#单篇辅助中文翻译)，软件反例见 [test_translation.py](../tests/test_translation.py)。本次没有实现 [#63](https://github.com/normaltank/DataBase/issues/63) 的自动任务或月预算，也没有调用真实付费API。

翻译迁移接在题录 12、引用 13、专题 14 后到结构版本 15，先完整备份并在事务中建表；冻结的非空 v11 应用夹具逐级升级，各阶段备份可恢复并继续升级，15 迁移失败回滚到 14。CSV、可读内容包及完整备份覆盖原译对应，恢复不自动执行任务。配置和使用见 [README](../README.md#单篇辅助中文翻译)。本功能不包含批量翻译、自动采集、身份确认、研究对象国或专题归类；真实供应商与专业译文质量需分别核验。
