知汇 · 本机演示包

面向研究中心，保存来源、原始资料和中心成果，支持主题编译与独立期刊编译的文件交接、审稿、版本和采用追溯。

所有随包样例、机构、作者、观点与出处均从零合成，明确标有“演示”；不是研究结果，也不是实际研究中心的账号或资料。

开始和结束

  1. 将整个 ZIP 解压到本机可写文件夹。支持中文和空格；建议使用较短路径，避免 Windows 长路径限制。
  2. 双击根目录 start.bat，等待首次初始化并打开浏览器。不用安装 Python、pip、Git，也不用管理员权限。
  3. 结束时双击 stop.bat。只关网页不会停止服务。再次启动保留新增内容、上传原件和历史；不会重置演示库。

仅监听 127.0.0.1；端口自动选择，避开 8848，并优先复用本包上次端口。重复启动打开同一实例。每份解压副本保存自己的 data 与登录会话，停止只控制这一份。

建议体验顺序

  1. 用 researcher 登录“编译协作”，查看“演示｜公共空间与地方协作（已汇总）”。展开候选、会议、初稿 v1、退回意见、返修 v2 定稿和汇总采用，下载并核对实际原件。
  2. 在“中心成果”查看各篇定稿与整期汇总，下载材料包。汇总固定采用 v2；之后上传新稿不会改写旧采用。
  3. 切到“期刊编译”，查看“演示｜波罗的海协作评论 · 2026年第1—2期（虚构）”。它独立于主题，两版原件保留，v2 是明确采用的当前成品。
  4. 在“资料”阅读三篇虚构原文、人工中文及出处，下载“演示原文.pdf”；在“档案”查看两家机构、期刊与两位虚构作者。
  5. 在“演示｜青年阅读与社区（进行中）”继续上传自己的合成选题报告。退出后用 colleague 登录，可接手记录会议、分工与审稿。请勿上传真实敏感材料。
  6. 用 admin 进入“维护界面”，体验核对、负责人资格及完整备份。备份包含当前演示库与账号，加入自己的内容后请自行判断分享范围。恢复方法见随包 构建与恢复说明。

运行范围和文件

核心阅读、录入、上传、下载、协作和导出可离线使用。联网题录、外部采集及翻译需要网络与另行配置，本包默认不启用采集、AI 或后台处理，也不携带开发机凭据。

data 首启才创建，是本包的持续资料；.portable 保存本实例控制状态与启动日志。移动或重新解压到新路径会改变本机登录身份；请先停止。转发原始 ZIP 可得到全新的独立演示，不要直接压缩使用后的文件夹。

根目录“项目介绍.pdf”适合首次了解项目；platform_app、templates、static 与 portable 保存运行源码。源码与长期规则另见 产品宪章、术语表及公开仓库。app.py 是开发入口，便携使用始终双击根目录 BAT。

内嵌 CPython 3.12.10 x64 与固定依赖供本轮兼容验证。该 Python 版本已有后续安全修订；运行时升级需要重新构建和验证。当前是本机演示，未证明所有 Windows 10/11 配置或正式生产环境均已适配。第三方许可与文件摘要分别见 THIRD-PARTY-NOTICES.txt、manifest.json 与 portable/runtime-lock.json。
