北外中东欧研究中心内部使用 · 本机与校园网试用

面向研究中心，保存来源、原始资料和中心成果，支持主题编译与独立期刊编译的文件交接、审稿、版本和采用追溯。

主题／期刊协作、演示人物和中心成果为明确标记的虚构样例。另含历史17国的38个核心来源、27个辅助机构与56篇真实公开资料题录：56个历史机器译题，23组原摘要及机译独立节选，33篇未取得原摘要。机器结果未人工校订，完整摘要、全文及内部资料未随包。

开始和结束

  1. 将整个 ZIP 解压到本机可写文件夹。支持中文和空格；建议使用较短路径，避免 Windows 长路径限制。
  2. 双击根目录 start.bat，等待首次初始化并打开浏览器。不用安装 Python、pip、Git，也不用管理员权限。
  3. 结束时双击 stop.bat。只关网页不会停止服务。再次启动保留新增内容、上传原件和历史；不会重置演示库。

仅监听 127.0.0.1；端口自动选择，避开 8848，并优先复用本包上次端口。重复启动打开同一实例。每份解压副本保存自己的 data 与登录会话，停止只控制这一份。

校园网临时试用

  1. 先用 stop.bat 停止本副本，再双击 lan-configure.bat。首次按提示隐藏输入新的管理员密码（12—200字符）。键入时不显示字符或星号，并非卡住，输入后按回车；短密码或确认不一致会提示重试，Ctrl+C取消。两次确认一致后，替换公开演示口令；仍使用默认口令的 researcher／colleague 会停用。资料、原件、历史及已有自设口令保留。之后启动不重置账号。
  2. 双击 lan-start.bat。窗口显示当前主机实际 IPv4 地址与端口，例如 http://校园网IP:端口；把窗口显示的地址给同事。浏览器默认打开主机本机地址。不要填写 0.0.0.0，它只表示监听方式。
  3. 用 admin 与新密码登录，进入“维护界面→成员”，为每位同事新建独立账号。也可给原 researcher／colleague 分别设置新密码并勾选“账号有效”；原 colleague 的负责人资格仍保留。为新成员分配负责人资格沿现有入口，管理员不会自动取得私人正文编辑权。
  4. 结束使用 stop.bat；再次 lan-start.bat 优先复用上次端口，冲突时显示实际新端口。切换回 start.bat 先停止；原新口令及停用状态继续保留，不恢复快捷登录。再次设置端口可在命令提示符运行 lan-configure.bat --port 8851，0表示自动选择，避开8848。

这是临时校园网 HTTP 试用，只在同一可信、可互访网络使用。正式服务器应按 部署说明入口 使用 HTTPS；本包不会开通公网、改路由器或自动修改防火墙。校园Wi-Fi的客户端隔离、访客网或不同网段策略可能阻止互访；先核对电脑当前IP，再请校园网络管理员确认。IP随网络变化时先停止再启动，重新分享窗口中的地址。

Windows防火墙如需放行，请由主机使用者在“高级安全 Windows Defender 防火墙→入站规则→新建规则→自定义”中选择本包 runtime\python.exe、TCP及启动窗口显示的端口；远程地址只填实际试用网段／具体同事IP，只勾选实际受信的校园网络配置文件，规则起可辨认名称。不要放行所有程序、所有端口或所有远程地址。端口变化需更新规则；试用结束停服务并禁用／删除这条规则。若校园网络被标为公共网络，请先咨询网络管理员确认受限范围，勿直接全局开放。此处只提供操作说明，软件不执行放行。

主机须保持联网、开机且不休眠；关盖休眠、关机或切网会中断同事访问。LAN页面没有演示快捷登录，远程设备不能调用本机停止控制。首次设置可能停用示例成员，恢复协作演示请按上面成员管理步骤分别设新口令。

可选：使用自己的DeepSeek与后台

原始ZIP不带密钥；全新目录默认AI暂停、没有采集后台。历史机器节选不会变成实时AI。只有管理员明确完成以下步骤才允许联网和按预算付费。

  1. 先用 stop.bat 停止本副本，再运行 lan-configure.bat 设置私有管理员口令并停用默认账号；本机模式也适用，这一步不会启动LAN。
  2. 双击 ai-configure.bat，隐藏输入自己的DeepSeek密钥（不显示字符或星号），填写模型、模型版本／核对日期、带版本的CNY价格与月预算，输入 SAVE 保存。Ctrl+C或不确认可取消；配置过程不请求模型，保存后仍暂停。
  3. 双击 ai-enable.bat，核对当前月预算，输入 ENABLE 明确启用，再运行 start.bat 或 lan-start.bat。两种入口使用同一设置，配置或重新启用前均须停机。
  4. 管理员进入“维护界面→AI与费用”查看后台、预算和任务。只处理已经启用的采集来源及已排中文／档案任务，不自动扩大信源或全库范围，不需要读者刷新。机器建议仍需人工采用。
  5. 双击 ai-disable.bat 暂停新AI调用，后台完成当前有界任务与费用结算后停止，阅读服务仍可继续。重新启用先停止服务、再执行第3步。结束本包用 stop.bat，等待在途任务结算，保留窗口直至显示停止；只关网页不会停止后台。

窗口默认价格取2026-11-03核查的 deepseek-flash 保守峰值（每百万tokens：命中0.04、未命中2、输出8元），使用前请按官方价格页核对。预算为UTC自然月人民币额度，0只允许暂停；预留和结算继续累计，未知费用阻塞新调用，重启不自动重试。月预算不等于账户余额或跨月总额。

密钥与本机设置由Windows当前用户加密保护，存放在解压文件夹之外，不进页面、日志、完整业务备份或分享ZIP。同一用户、同一路径重启保留设置与data；移动路径、换电脑／Windows用户或恢复到新目录须重新配置和明确启用，默认暂停。维护界面的当前月预算在暂停、重新启用及重启时保留；再次运行配置向导会设置新的月预算。更多恢复边界见构建与恢复说明。

建议体验顺序

先找真实资料：登录 researcher，进入“我的”→“资料夹”→“历史17国公开资料样本”，可查看全部56篇；也可进入“资料”搜索 平台工作者。打开文章后切换中文／原文，查看来源网址。摘要为节选，原文与机器译文分别截取，未必逐句或逐段对齐；历史版本保留来源与独立校验值，本包没有新发翻译调用。

  1. 用 researcher 登录“编译协作”，查看“演示｜公共空间与地方协作（已汇总）”。展开候选、会议、初稿 v1、退回意见、返修 v2 定稿和汇总采用，下载并核对实际原件。
  2. 在“中心成果”查看各篇定稿与整期汇总，下载材料包。汇总固定采用 v2；之后上传新稿不会改写旧采用。
  3. 切到“期刊编译”，查看“演示｜波罗的海协作评论 · 2026年第1—2期（虚构）”。它独立于主题，两版原件保留，v2 是明确采用的当前成品。
  4. 在“资料”也可阅读三篇标记“演示”的虚构原文、合成中文及出处，下载“演示原文.pdf”；在“档案”区分真实公开来源与虚构演示机构、期刊及作者。
  5. 在“档案→作者档案”打开“演示｜安娜·河港”或“演示｜马丁·北岸”，点击“查找公开介绍”，查看完整虚构介绍、合成建议及出处：一人保留待人工采用示例，另一人保留已采用／拒绝历史。查阅这些现有示例不联网、不调用AI、不产生费用；为实际人物取得介绍并生成新建议，须先完成上方本机AI配置与明确启用。
  6. 在“演示｜青年阅读与社区（进行中）”继续上传自己的合成选题报告。退出后用 colleague 登录，可接手记录会议、分工与审稿。请勿上传真实敏感材料。
  7. 用 admin 进入“维护界面”，体验核对、负责人资格及完整备份。备份包含当前演示库与账号，加入自己的内容后请自行判断分享范围。恢复方法见随包 构建与恢复说明。

运行范围和文件

核心阅读、录入、上传、下载、协作和导出可离线使用。真实样本来自既有批次的辅助RIS整理和历史DeepSeek结果，不能据此认为38站持续接通。全新目录默认不启动采集、AI或后台处理，不携带开发机凭据；明确完成上方本机配置和启用后才运行既有后台，新调用单独记账。访问外部原站仍需网络；此次历史平台取得曾因保留地址解析而受阻。

data 首启才创建，是本包的持续资料；.portable 保存本实例控制状态与启动日志。移动或重新解压到新路径会改变本机登录身份；请先停止。转发原始 ZIP 可得到全新的独立演示，不要直接压缩使用后的文件夹。

根目录“项目介绍.html”（旧版也支持PDF）适合首次了解项目；platform_app、templates、static 与 portable 保存运行源码。源码与长期规则另见 产品宪章、术语表及公开仓库。app.py 是开发入口，便携使用始终双击根目录 BAT。

内嵌 CPython 3.14.10 x64、Waitress 与固定依赖，版本和官方构件hash已锁定。运行时升级需要重新构建和验证。当前支持本机演示和明确启动的临时LAN试用，未证明所有 Windows 10/11 配置或正式生产环境均已适配。第三方许可与文件摘要分别见 THIRD-PARTY-NOTICES.txt、manifest.json 与 portable/runtime-lock.json。
