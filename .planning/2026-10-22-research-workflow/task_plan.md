## Decisions Made
| Decision | Rationale |
|----------|-----------|
| 仅指挥 Agent 更新本目录与 PRODUCT/需求讨论记录 | 避免多个 Agent 重写同一权威文件；建设方维护实现记录。 |
| 前端/后端分工已明确交接 | 建设 Agent 确认停止写 static/templates 后，采集 Agent 独占该两目录；建设方继续独占后端/迁移/tests。指挥方最终独立验收。 |
| 在现有 Flask/SQLite 上增量施工 | 用户需求不要求换技术栈；保留已有数据和主题。 |
| 按批次实现但不为已授权步骤重复求批准 | 用户已明确启动所建议的建设顺序。 |

## Errors Encountered
| Error | Resolution |
|-------|------------|
| 初次合并读取输出被截断 | 按目标章节重读需求记录；后续限制单次输出。 |
| 前端接线中先后出现未定义 currentEditorForm / updateEvidenceMode | 已补齐启动与可选依赖保护；指挥方随后成功恢复原草稿并验证冲突保稿与提交，问题已关闭。 |
| 独立 B/C 脚本误将布尔值用于列表推导 | 修正测试脚本，使用全新合成运行目录复跑；不是应用故障。 |
