# 北外中东欧研究中心内部使用

一个可以在本机使用、数据可以持续保存的中文研究资料平台，以拉脱维亚资料试点，优先保存中心主题与期刊编译的交接、过程和成果，同时保存支撑它们的来源与原始资料，支持中文阅读、简单资料夹和成果复用。实现范围和已知缺口见 [施工说明](docs/施工说明.md)，各轮交付与验收见 [文档目录](docs/README.md)。

## GitHub 版本与本地数据

公开仓库 [normaltank/DataBase](https://github.com/normaltank/DataBase) 保存应用源码、自动测试、产品规格和建设交接文档。研究数据库、成员凭据、上传附件、备份包、运行日志、验收原始数据和本机截图均留在本地，不随 Git 上传；源码仓库不能代替完整数据备份。

本文的 143 条来源、494 条资料等数量及验收记录描述原本机试点状态，克隆仓库不会附带这些资料。新环境按下文安装依赖后，可用 `python app.py --no-import` 启动空白资料库，通过本地演示账号体验并自行录入；需要迁移实际研究资料时，另按备份恢复流程交接。历史记录中指向忽略目录、截图或本机绝对路径的证据，只能在保留这些文件的原环境查阅。

## 打开和关闭

**双击本目录的 `start.bat`。** 程序会在后台运行并打开浏览器，入口为：

<http://127.0.0.1:8848>

登录页可以直接选择“研究员”“资料管理员”或“协作同事”体验。也可以填写以下本地演示账号，密码均为 `LocalDemo2026!`：

| 账号 | 身份 | 可以做什么 |
| --- | --- | --- |
| `researcher` | 研究员 · 林 | 提交资料和成果、共同维护可见的非报告内容、按授权编辑个人报告、收藏和整理资料夹 |
| `colleague` | 研究员 · 周 | 同样的成员功能，可用于检查不同账号的查看和编辑范围 |
| `admin` | 资料管理员 | 成员功能、核对、成员和备份管理；个人报告正文仍需作者授权 |

结束使用时双击 `stop.bat`。只关闭浏览器不会关闭后台程序，停止程序不会清空数据。再次启动会使用原有资料。

当前仍为本机运行：演示入口和固定密码用于试用。本轮增加本机成员创建、停用和密码管理；正式名单、联网部署、HTTPS 与运行安排仍须另行确定。

## 建议先试这条流程

保存已有整期期刊成果：打开“中心成果→期刊成果”或主导航“期刊成果”，选择“保存一期成果”，填写刊名、年份、成果期次并选择首批文件即可。无需先建立期刊档案。打开一期后可预览、下载、添加并列文件；需要修订时，点击对应文件的“更新这份文件”。此前版本与修改人保留在该文件历史，期次信息由中心成员共同维护。相同刊名／明确关联期刊、年份和期次重复保存时，会提示打开已有一期。

期刊成果按年份从新到旧、期次原标注倒序排列，可查刊名、期次或文件名。已关联期刊可进入本刊文章与期刊档案，浏览器返回保留查找条件、未提交搜索文字和焦点。PDF打开原件预览；Word提供有界文字预览，版式阅读下载原件。一次上传合计最多20 MB，更多文件分批添加。本期“修改历史与导出”可导出元数据及全部版本；历史恢复会新增版本，不覆盖旧原件。旧期刊工作与原有采用关系仍从历史入口查阅。

1. 选择“研究员”，进入“编译协作→我参与”。通过业务下拉框筛选主题、期刊或全部，点击工作题名，在右侧接续该工作的原件与具体版本；窄屏打开独立详情，点击“返回工作清单”继续。当前范围为空时，可直接“查看全部可读工作”“查看期刊编译”或“浏览资料”。
2. 主导航“资料检索”可打开新文章，切到“全部资料”搜索题名、摘要、原文、来源或作者。无结果时点击“重置筛选”或“查看全部资料”；阅读工具栏直接提供收藏和加入资料夹，点击“返回列表”继续原检索。
3. 收藏一篇资料，或加入“拉脱维亚 · 语言与社会”资料夹。
4. 打开“中心成果”→“独立成果与跨期译稿”，查看“操作示例｜拉脱维亚语言与社会资料整理”。这份演示记录关联了两篇真实资料，并有可下载的操作说明。它不是正式研究成果。
5. 在“中心成果”点击“导入成品”，上传已经完成的报告及原文件：填写题名和编译者，查找并添加多篇原文；原文未入库时，填写待补关联的出处。
6. 新上传附件需确认可在所选范围共享。支持 PDF、DOCX、UTF-8 TXT/Markdown，单文件最大 20 MB。
7. 切换“协作同事”，检查同事可查阅共享成果，但不能编辑未获授权的成果。
8. 切换“资料管理员”，打开待核对资料并标记已核对。之后编辑会重新变为待核对。
9. 通过“历史”恢复旧版本；恢复形成新版本，保留当前授权及共享范围。

清单导出沿用当前检索条件、专题和查看权限。个人收藏和个人资料夹只对本人显示；共享资料夹允许成员共同添加和移出资料。受限资料按提交者、负责作者、有效授权及管理员的读取范围控制，加入共享专题不会扩大资料本身的权限。

## 研究界面与维护界面

研究员登录后使用“编译协作、中心成果、资料检索、来源与作者档案”，个人区提供资料夹、收藏和个人空间。公共档案和可读公共内容继续共同编辑，个人报告仍由负责作者及其授权同事编辑。“个人空间”提供修改本人密码与导出可见内容；资料列表中的批量整理、资料夹及正常导入导出继续可用。

在“资料检索→整理与导出→整理个人成果重复”中，可查找本人或已获编辑授权的个人编译成果、个人研究报告，选择两条后比较内容与关联，再明确确认合并。公共资料与无权编辑的他人成果不列为个人候选；服务器在比较及执行时继续核验两条的作者授权、可见范围和编辑授权是否相容。公共资料的“整理重复”和“整理重复来源”由管理员在维护界面使用。

资料管理员在研究界面点击“维护界面”，切换到来源维护、数据核对、自动采集、中文处理与费用、账号与负责人资格、完整备份的独立导航；点击“返回研究界面”继续日常工作。负责人资格在维护界面登记，具备资格的业务负责人仍在研究界面开期和审稿。普通成员打开旧“管理”或其他维护地址时会看到身份说明，可返回研究界面或“个人空间”。

### 提供采集来源与管理员接手

1. 在“来源与作者档案→机构与刊物”或“个人空间”点击同名的“提供采集来源”。填写名称和来源类型，提供官网或资料目录网址其一；国家线索、推荐说明可选。智库按机构类身份保存，期刊不自动猜主办方、ISSN或国别；档案细目可在保存后共同补充。
2. 点击“保存候选来源”后进入对应档案，明确显示候选、待核对及采集状态；保存不会自动启用采集。错误或重复保留当前输入，重复时可点击“保留草稿并查看已有来源”。仅需了解实际适配器时，展开“采集支持范围与档案补充”。
3. 管理员进入“维护界面→来源维护”，默认查看待核对来源，可按名称查找、查阅依据、编辑并记录核对范围与说明。切换“全部来源”可继续查找已核对或其他既有来源，资料发现网站也在同一列表。
4. 档案分别显示来源核对状态和持续采集情况。当前支持 LIIA Opinions、GSSC Publications、CJIR、Intersections 的固定官方入口及三刊公开JSON题录；其他新来源显示“尚未接入持续采集”，登记或核对不代表已经取得文章。管理员须在“自动采集”另行启用实际支持的来源，研究员不用填写采集规则、模型凭据或费用配置。来源贡献本身不建立审批进度；AI字段建议的核对采用见下文。

本节描述 #75 的程序使用路径；本轮开发验证和正式部署状态见[施工说明](docs/施工说明.md#研究与维护界面及轻量来源贡献2026-10-2975-开发验证)，不将分支实现视为真实库已经更新。

## 并列工作台

桌面以固定导航、工作清单与实时交接栏组织。点击工作或稿件行后，清单仍在同一视野中；主题的“选题材料／编译材料”分别显示相应材料，期刊独立保存其原刊范围和实际采用文件。需要查看全部过程时可打开“完整档案”。工作标题查询与参与人条件分开；未知状态不计为零，也不推断整期完成。

手机先查清单，再打开完整详情，返回时恢复位置与焦点。资料阅读同样支持列表与阅读区域往返；正文与元数据至少14px。界面tokens、布局及组件约定见 [DESIGN.md](DESIGN.md)，实际组织入口由 `static/workbench.js` 维护，领域模块继续负责保存、权限、原件和冲突处理。

## 主题编译与选题报告交接

进入主导航“编译协作”。管理员进入“维护界面→账号与负责人资格”，打开“负责人资格”，为实际负责人登记或撤销资格；资格与资料管理员角色分别管理，停用账号不能使用资格。

1. 负责人展开“发起工作→开启一期主题”，填写主题，选择参与成员及可选日期；负责人自动参与，可单人体验。
2. 在“选题材料”展开“上传选题材料”，选择本机 DOCX、PDF、TXT 或 Markdown（最多20 MB）。题名和说明可选，同一人可上传多份材料，无需创建文章、会议或分工。
3. 文件旁“查看内容”提供可提取文字预览；版面、图表或无法预览的内容用“下载原件”在本机打开。成员和负责人均可按原权限读取，原文件字节及文件名保留。
4. 负责人展开材料旁“审阅此版”，选择退回或通过；意见及附件可选。作者展开原材料的“提交新版本”继续交接，新版重新待审，旧版与决定仍可展开阅读。通过不自动发布成果。
5. 负责人点击“进入编译”并确认，不要求会议、文章分工、全员交齐或通过。两个材料页签只切换查看范围；进入编译后仍可在选题页签补交材料。
6. 编译材料沿用上传、退回、新版本及通过的操作。本人兼负责人可完成全部操作；负责人不能替其他作者上传新版，纯维护管理员不能代行审阅。
7. 在“本期信息与收尾”中选择“结束本期”，结束后暂停期内写入，材料与导出继续可读。负责人可“重开本期”恢复原阶段。结束无需汇总或全员审阅完成。
8. 冲突时保留当前文件和输入，先“刷新状态，保留输入”再继续；请求结果未知时直接重试沿用同一请求，不重复生成版本。账号切换后须重新打开材料操作。

“材料包与历史”可下载明确范围的材料包，并按需查看旧会议、分工稿件、退回、定稿、汇总及固定采用。旧材料由本人提交真实新版后接续，原历史保持原作者和版本。旧候选专用下载网址仍只覆盖候选报告；统一材料包包含新旧流程。

### 材料沿革与逐版意见

每份材料直接显示“成员提交／负责人审阅”两条责任轨道。点击版本或审阅节点，下方阅读区同时切换到那一版原件、提交说明、具体意见和审阅附件；连线仅对应实际审阅。当前版与历史版有文字标记，“回当前版”回到最新提交，新版待审不会沿用旧版通过。窄屏和放大时可用“选择版本”或顺序文字节点完成相同操作。

“当前操作”明确审阅绑定的版本和新版本接续的材料。查看历史、查看另一份材料或点击“刷新材料状态”保留页面内现有文件选择、输入和表单目标；刷新后原目标已不可操作时保留草稿并停用保存。冲突继续使用表单内“刷新状态，保留输入”，不把旧审阅自动改投新版。完整重载网页后须重新选择本机文件。材料读取失败保留此前内容并提示未更新，明确失权时停止显示材料内容。

## 中心成果查找与材料包

“编译协作”和“中心成果”位于主导航“研究中心”。协作默认“我参与”，业务下拉框可切换主题、期刊或全部；“我负责”按当期主题负责关系及个人期刊成果负责作者显示。撤销主题负责人资格后，原期次仍可找到，维护与审稿动作按当前有效资格核验。主题列表显示当前选题／编译阶段及已结束标记；闭期仍可按参与／负责身份找到。目录译稿继续共同维护，不另设负责人审批；其他可读期刊工作可从“全部可读”查找，管理员另从“维护界面→协作维护查阅”进入。支持主题／刊名、国家分工、参与人和最近修订时间查找，标题列表最新在前。

“重置查找”清空关键词、国家分工、参与人和日期条件，保留当前业务及工作范围；通过业务下拉框切换主题／期刊／全部业务，通过上方标签切换“我参与／我负责／全部可读”。

“中心成果”优先显示各篇已确认定稿、最新整期汇总和期刊当前采用成品。后来交新稿不使旧定稿或旧汇总改用新文件。进入所属工作可以展开历史、会议和返修；从查找进入后，“返回主题／期刊工作”保留原条件。成果正文内的工作关系只向当前也有权读取工作的人显示。

期刊工作中的“提交期刊文件”保存编译稿、审稿材料或成品文件及其版本；上传成品文件后，仍须在该文件旁点击“作为当前成品 vN”记录实际采用。上传不会自动采用，也不套用主题审稿流程。主题工作默认显示当前阶段材料；两个页签只切换查看范围，负责人另用“进入编译”推进。旧会议、定稿及汇总按需查历史，不是新上传、推进或结束的前置。

旧独立报告和跨期目录译稿从“独立成果与跨期译稿”继续查阅；“全部资料与旧研究积累”保存现有查询条件，能找到笔记、说明、摘录及原有文件、引用和历史。旧笔记类型链接会带条件转到全部资料，无需重传或补挂一期。个人报告的历史仍按作者授权读取。

在任一期工作展开“下载本期材料包”，明确选择：

- **成果原件：** 主题包含全部已确认定稿与各版整期汇总，以及汇总实际采用的原件；期刊仅包含当前明确采用的成品。历史采用决定保留，范围外原件不会被宣称已导出。
- **过程材料：** 主题包含两阶段材料及审阅、旧选题报告、会议、稿件和返修意见，不含定稿决定与汇总；期刊包含当前成品之外的已提交原件及工作、采用历史。
- **全部已提交材料：** 所选工作的全部已提交原件、版本、决定与采用关系。未提交文件、其他期次、关联成果正文和附件及关联原文不在本包内；这些内容按各自权限另行查阅。

主题材料包说明的是导出时当前阶段及结束状态，人工转换、结束／重开事件、当时确认的缺项依据与升级来源单独保留，不将当前状态套成每份旧材料提交时的状态。

包内 `README.txt` 说明覆盖范围，`manifest.json` 列明原名、版本、提交人、决定、精确采用关系和每个原件的 SHA-256。导出逐文件写入临时 ZIP，完成并重新核权后才发送，失败不返回半包。可用仅依赖 Python 标准库的独立工具核验：

```powershell
python scripts/verify_work_materials.py "材料包.zip"
python scripts/verify_work_materials.py "材料包.zip" --sha256 "从独立可信渠道保存的整包SHA256"
```

工具不运行平台代码，也不解压执行包内内容；检查文件字节、清单缺项／多项、工作与版本归属、范围、审稿和汇总采用关系。内部一致性不能证明来源真实性或未导出内容的完整性；需要时将整包散列、采用原件与独立保存的文件或在线版本逐一比对。已同时改写所有声明的恶意重造包不能单靠自带清单鉴真。


## 资料库选择与批量整理

主导航优先呈现“编译协作”“中心成果”，“资料检索”“来源与作者档案”继续便捷可达。“个人空间”汇集收藏、资料夹、未提交草稿、关注条件、个人密码及可读内容导出；管理员通过“维护界面”切换到专用维护导航。窄屏点击“打开导航”，选中页面后收起，也可用 Escape 关闭。旧资料、来源、作者、收藏和草稿路由继续有效。

“资料”默认新文章，按账号固定一批尚未确认浏览的文章。初次或距上次确认超过30天时先显示近30天收录，点击“查看全部新增”可找回较早未确认内容。打开首页、翻页和阅读不会自动确认；点击“结束本次浏览”后，先核对数量与当前条件，再明确确认。只确认当前筛选结果，其他未浏览新增留到下一批；正在浏览时后来入库和补译不会挤乱本批顺序。同一收录时刻按发表日期降序、原题名升序排列，再保存本批编号序列。发表、首次收录、最近修订分别显示和筛选，补收旧文章仍是新增。

空批次之后有新文章入库，刷新或重新登录即可取得。非空批次中，每组筛选第一次读取时固定成员与次序；翻页、返回、重登、清单和内容包导出复用同一范围，题名与摘要仍显示当前版本。稍后补译才匹配的文章留到下一批，不加入正在确认的范围。权限始终实时检查；确认前可见范围已变化时，页面要求“保留条件，重新读取”，核对新数量后再确认。

当前筛选为空时也可点击“结束本次浏览”，明确确认0条并按原条件重新查找；这不会确认任何未读资料，全部未浏览内容留在下一批。

默认以可用中文题名紧凑显示，摘要进入条目后读。人工中文字段优先；没有人工中文时采用与当前原题名／摘要输入匹配的最新成功机器版本，明确“机器中文，尚未人工校订”。只校订题名时摘要保留并明确标作原文摘要；原始中文资料也属于可读中文。原始字段和所有译文任务继续保留；中文、原文可切换，缺原摘要和中文待处理分别说明。中文译题、摘要和原始信息均能检索，导出保留当前阅读投影、版本类型及原译依据。

国家、关键词与时间可直接使用，“时间与更多筛选”提供自定区间、来源、来源国别／类型、文章类型、主题、语言及内容可用性。每项可多选，计数只包括当前账号在当前结果范围内可读的资料；没有登记研究对象的资料可在“未知／待分类”找到。来源国别按既有机构登记或主办国别依据，文章研究对象由文章内容登记，两者独立。重置保留当前来源／资料夹等固定范围，收藏、成果、待核对页保留自己的用途范围。

国家的确定中英文及大小写别名归为同一中文选项，同一资料同国只计一次。已选国家可以继续增减，零结果条件仍可取消；“更多筛选”只数内部生效的条件，默认发表时间不产生条件标签。旧网址与常用检索继续接受原写法，清单和内容包使用同一查得范围，导出原字段及已冻结批次成员保持原据。词表来源、版本及更新边界见[国家名称词表](platform_app/country_data/README.md)。

发布日期筛选按可能日期范围包含资料：例如仅登记 `2026` 的资料会进入 `2026-02-01` 当天的筛选，仅登记 `2026-02` 的资料也会进入该结果；完整日期精确到当天。日期未知或无效时，有日期条件的查询不收录该资料；原始年份、年月或日期精度始终保留。查询起止值使用有效的 `YYYY-MM-DD`，起始日期须不晚于截止日期。列表、候选、常用检索重查、清单及内容包导出采用同一筛选规则。

提交资料和维护来源时，发布机构、刊物、关联来源、主办／出版方及机构关系使用可搜索的选择区。已选值单独显示，缩小候选不会删除已选项；需要取消时直接移除对应已选值，多选不再要求按住 Ctrl。专题内的“清除筛选”保留专题范围，单独移除专题条件或从导航进入资料库才回到全库。

资料库默认使用紧凑列表，也可切回卡片视图；切换保留当前查找、排序、页码及选择。打开题名后，足够宽的屏幕可同时查看列表与正文，使用“上一条／下一条”、j／k 或 Alt+↓／Alt+↑ 阅读同页资料；在输入框、编辑区、输入法组合或弹窗内不会触发阅读切换。“返回列表”恢复原来的浏览位置。中等及窄屏使用独立阅读区域，加载期间也可返回。在有搜索框的页面，按 / 或 Ctrl+K（Mac 为 ⌘K）聚焦搜索；输入和编辑时保留原按键。

阅读工具栏的 A−／A+ 可选择17、19或21px字号，“衬线”切换本机字体；浏览器允许存储时刷新后继续使用，禁用或损坏存储不会阻断阅读。篇幅与用时只估计当前正文，缺正文时标为摘要；顶端细线表示当前阅读位置，两者都不代表已读或研究完成。复制成功显示“已复制”，失败时可手动选择文字。

从阅读中的资料进入人物或来源档案，点击“返回资料”可恢复原检索、页码、视图及正在阅读的资料；同一账号的浏览器前进、后退和刷新也保留有效工作位置。专题打开资料再关闭时，返回原专题的查询与页码。原资料已不再可见或不在结果中时，返回当前可用列表并说明原因。

展开“整理与导出”，点击“批量整理”后逐条勾选，或用“选择当前页”选择本页资料；最多 100 条。选中后显示批量操作与选中数量。同一查询翻页保留选择，改变查询、筛选、排序或离开资料库会清空并提示。选择按账号隔离，刷新后不恢复旧选择。

“收藏选中”只添加收藏；“加入资料夹”选择一个自己可维护的专题，已有条目保留一份。结果显示处理、新增及原有数量，保留当前选择便于继续整理。服务端会重新检查每条资料和专题权限；编号失效、权限不足或专题版本冲突时整批不写入。失败保留选择；专题冲突时点“重新读取专题”，核对后再次确认。

“导出选中 CSV”仅下载明确勾选且当前可读的题录，支持中文、引号和多行，并处理电子表格公式起始内容。工具栏原“导出清单”继续按筛选条件导出。批量整理不改正文、作者身份、共享范围或编辑授权。

## 地图、关联探索与资料比较

以下为本轮分支的使用入口，统一审查与交付见[父任务 #122](https://github.com/normaltank/DataBase/issues/122)及[PR #126](https://github.com/normaltank/DataBase/pull/126)。本轮尚未更新现用便携副本或真实资料库。

1. 在资料列表展开“地图与时间”。地图默认欧洲，可切换“全世界”；点击国界或下方国别文字按钮，以资料的研究对象国筛选原列表。“国别未知”和标有“无地图”的登记值也可通过文字入口查找。分布覆盖当前完整可见查询，不限当前页；多国资料分别计入各国，数量只表示库内资料，不代表研究热度或覆盖完整性。
2. 在“时间分布”的“浏览口径”选择发表时间、首次收录或最近修订，再点击年份或该口径的未知入口筛选。切换口径只切换分布展示，再选年份或未知项才应用时间条件；仅年、年月、完整日期的登记精度保留。国别与时间条件联动原查询，保留关键词、固定来源、资料夹及新文章批次范围；分别用“清除研究对象国条件”“清除时间条件”取消新增条件。
3. 打开一篇资料，在正文前展开“关联探索”，可按已登记关系进入正式关联的作者、机构作者、发布机构、刊载期刊、文章署名单位、关联原始资料及引用本篇的研究笔记或中心成果。AI 正式关联标明机器来历，与人工确认分别显示；原始未确认署名单列，文章署名单位不表示作者任职。阅读中的“指出问题”可直接提交纠错。档案中的“返回资料”或关联资料中的“返回前一篇”用于接续原阅读；无可查看关系时显示“尚未登记可查看的关联”，读取失败可重试。
4. 在“整理与导出”点击“选择资料比较”，勾选2–3篇后点击“比较已选资料”；同一查询可跨页选择。比较按项展示原始与中文题名、摘要、原始署名、来源、发表时间、首次收录及内容可用性，并区分人工中文、机器中文、原始中文和缺项。点击“阅读这篇”后可“返回比较”，也可“打开原文”；“关闭比较”保留选择及列表位置。多于3篇须减少选择；失效或无权资料明确提示，可重试或移除该项。

比较只对照明确选择的资料，不生成研究判断；权限和新文章冻结成员继续按既有规则核验。

## 个人常用检索

设置好关键词、筛选和排序后，展开“整理与导出”并点击“保存检索”，输入名称保存。下次从“个人空间”→“关注条件”或“整理与导出”→“我的检索”按名称查找并打开；保存的是查询条件，不保存临时批次编号和结果序列。“全部资料”每次重新查询当前可见资料；“新文章”把这些条件应用到当前批次，保持上文的稳定范围，新收录或后来匹配的资料在下一批出现。收藏、编译成果和待核对页面保存时保留其范围，重新打开从第一页开始。

“我的检索”可改名、用当前条件更新、另存一份或删除。修改当前页面的条件不会自动覆盖已保存检索；同名、保存冲突和请求失败会提示并保留输入。检索属于当前账号，删除检索只移除这份个人设置。

来源或专题已失效、无权访问时，页面保留原条件并提示调整；明确移除失效条件或选择其他条件后再保存。系统不会悄悄扩大搜索范围。完整数据备份包含个人检索；它与手动收集资料的资料夹分别使用。实现及验证见[本轮验收](work/常用检索与资料工作流验收.md)。

## 用 DOI 或文章链接提交资料

在资料库点击“提交资料”，将 DOI、DOI 链接或公开文章网址粘贴到顶部，点击“识别并填写”。成功取得的题名、作者、日期、刊物名称、DOI 和链接会直接补入空白字段；核对后点击“保存内容”才正式入库。普通资料只要求题名，其余按已知信息补充；正文、附件和“更多信息（选填）”可以按需展开。

默认保护手填内容。需要替换已填字段或关联档案时，展开“核对作者身份、来源或替换已有信息（选填）”，明确选择后应用。重复取得相同结果会保留人工修改和选择；取得不同结果需明确改用，届时只更新仍未手改的旧自动字段。草稿包含取得依据和核对选择，可从“我的草稿”恢复，包括自动取得的非预设语言。

姓名、ISSN、已有外部标识和官网地址只用于提出已有档案候选。选择作者／机构身份后，须明确确认并填写依据；未确认署名保留原文，之后再补档或纠错。发布机构和所属刊物需要明确选择，不会由出版社推断主办国别，也不会由文章单位推断任职。已收录候选可直接查看，保存时再次检查重复。

DOI 使用 Crossref／DataCite 的公开题录，网页优先读取文章标签和结构化信息。部分智库网页只能取得题名或说明，缺项继续手填；失败不会清空已填内容，可把输入网址放入空白原文链接。保存后的详情与可读导出保留取得来源、时间及当时题录。本功能不自动下载全文或附件，也不代表资料已经核对。

## 官方来源自动采集与原文快照

三刊公开题录使用 East European Politics（2159-9165 / 2159-9173）、Journal of Balkan and Near Eastern Studies（1944-8953 / 1944-8961）、European Union Politics（1465-1165 / 1741-2757）的固定 Crossref JSON 入口。未登记时可点“登记三刊公开来源”，登记本身保持停用；然后在各来源设置中明确启用。便携版另须在“本机公开采集”选中允许的期刊并开启，AI可保持关闭。暂停本机许可或单个来源后停止对应的新派发；正常停止／同路径重启保留选择。分享包及新目录恢复默认关闭本机许可，来源业务配置保留。

按[Crossref于2026年8月发布、9月补充的现行分页说明](https://community.crossref.org/t/changes-to-cursors-filtering-and-sorting-in-the-rest-api/16246)，cursor不再定时过期、每页会变且须带齐原请求参数；分页结果会随重索引变化，不是稳定快照。本实现保存窗口和每页next-cursor，后续分页请求实际返回HTTP400时才保留同一窗口重新读取并按DOI去重，不按旧版五分钟规则清除游标。固定截止日、重叠和去重减少遗漏，但不据此承诺完整镜像。

每轮一个请求、最多25条，沿用15秒／1MB公开传输限制。首轮检查最近30天的Crossref indexed窗口；窗口未取完则保存游标、约30秒后接续，取完后按来源频率开始下一窗口，并重叠上次截止日以接到后补元数据。维护界面显示实际窗口、页数条目、继续位置及失败；只证明该入口响应范围，不是全历史镜像或原刊完整目次。直接保存已返回的题录、逐作者署名、日期及实际提供的摘要；缺摘要、卷期留缺，原日期字段和完整JSON字节可下载。旧记录追加取得依据，人工字段及核对状态保留。“本刊资料”进入既有资料阅读、检索、收藏和资料夹。

控制端有界实采使用 `python scripts/collect_journal_sample.py --data-dir <已有目录> --source-id <明确期刊ID> --output <本地报告.json>`；最多重复三个 `--source-id`，每刊仅请求最新online日期题录最多5条。先停用该目录正在运行的后台以释放worker锁，所选来源须已明确启用且没有在途／等待运行；脚本遇到冲突会退出。它沿用持久采集保存路径，不调用AI、不扫其他来源、不改变既有indexed水位或本机许可。控制端真实结果与开发模拟检查分别留证，返回少于5条照实报告。


管理员进入“维护界面”→“自动采集”，在既有来源档案确认适配后，勾选启用并保存。当前支持 LIIA Opinions、GSSC Publications、Czech Journal of International Relations（CJIR）及 Intersections 的固定官方入口。默认每日巡检、首次取包含当日的 UTC 日历最近30天；“安排立即巡检”只安排持久任务。独立后台取得 RSS 和条目网页，题录自动进入共享资料、保持待核对；成员无需逐篇保存或持续登录。默认排除题名明确的招聘、登记等事务通知，可改为全部当前条目。管理员可明确扩大日期回溯窗口（30—3650天），只检查当前目录响应中的有日期条目，不遍历全站历史。其他来源不会因登记官网而自动启用。

“选择此来源用于批量操作”只决定本次操作范围，与“启用持续采集”分别设置。可全选下方已接入、当前未处理中的来源，或清空选择；已选数量和名称始终显示。未接入来源列出原因，不进入全选范围。“启用并保存所选”／“停用并保存所选”会一并保存这些来源当前的间隔、纳入规则与回溯窗口；也可仅“保存所选设置”或逐项保存。单项保存、失败和“刷新状态（保留草稿）”不会清除其他未保存参数，等待期间的新修改继续标记为待保存。

巡检仅安排已保存、已启用且没有未保存修改的所选来源；按钮显示本次可巡检数量。每项显示实际结果，失败项保留输入和选择，可在对应来源保存或重试。请求等待期间会阻止重复安排；响应丢失后重试同一操作沿用请求标识，已接收的任务不会重复建立。巡检、重跑仍遵守站点退避与管理权限，不表示已经取得新资料。

使用 `start.ps1` 会同时启动网页和同一数据目录的采集后台；`stop.ps1` 同时停止两者。单独运行后台可用 `python -m platform_app.ingestion --data-dir <目录>`，`--once` 处理当前可运行任务后退出；独立起停脚本为 `start-ingestion.ps1`／`stop-ingestion.ps1`。后台默认每30秒检查持久队列，任务短时中断后等120秒租约到期继续。持续服务需要常开主机；本机进程启动不表示正式持续运行已有保障。

隔离演练须使用新目录及 `--no-import`，避免读取默认 ThinkTank 输入。例如 PowerShell：

```powershell
.\start.ps1 -Port 8903 -NoBrowser -NoImport -DataDir C:\Temp\liia-demo
.\stop.ps1 -DataDir C:\Temp\liia-demo
```

管理页显示后台最近心跳、最近尝试、最近成功取得官方目录、下次巡检和每轮阶段／尝试／条目结果。“最近成功”指成功取得及解析固定 RSS／列表，不保证所有文章页成功；单条失败单独说明，可点“重跑失败条目”。没有新条目、RSS 失败、文章页失败和受限重复分别表达；只检查固定 RSS 或 GSSC 当前列表页，窗口、最早日期、排除、hash及继续取得位置可展开，目录原字节保存在完整备份并可由管理员接口下载。LIIA RSS 通常只返回20条；两个 OJS 期刊完整扫描当前有界响应，不在第一个旧条目处提前停止。零条不证明来源没有更新，未遍历分页或保证历史补齐。

原站返回 HTTP 403 时显示访问受限。HTTP 429 或带 `Retry-After` 的 HTTP 503 会暂停本轮后续条目，保存已取得的题录与未处理队列，并显示退避截止时间；退避批次暂不更新“最近成功”。重启、提前点击立即巡检／重跑或停用再启用均不会提前抓取，到期后续作原轮次。缺失、无效或过期的等待时间按一小时处理，超长值限定为七天并注明。该退避用于已接入的固定来源流程；尚未实现通用网站采集或 robots.txt 自动检查。

阅读页“自动取得与原文快照”保存来源网页的原字节、清洗说明、网址、取得时间、摘要值及适配版本，阅读时直接提供网页说明与原站入口，侧栏角色、摘要值、适配版本和原始页面下载收于可展开的“取得依据”；原页脚本不在阅读面执行。当前 LIIA 适配器对落地页、节目介绍及参与说明统一保守标作“来源网页说明／未取得所指作品正文”，不把公开描述或点号当原始摘要，也不按字数推断已取得作品全文。正文内原署名与侧栏署名一并保留，角色可能不同；对象国不由机构所在地推断。未配置自动中文与月额度时仅留下持久待处理状态，不调用 AI。GSSC 只在实际辨认官方文章正文容器时提供 HTML 正文与位置依据，导语和作者简介独立于正文。CJIR／Intersections 保存正式题录、原摘要、逐作者标识和官方 PDF 链接；PDF未下载，不表示保全全文。文章引用日期、RSS上线／发布标签、DC issued／created／modified 原值与首次入库时间分别保存，可在取得依据中核对冲突，不能互相改写。Intersections 近期无条目时如实为0；需要旧条目时由管理员明确扩大回溯窗口。

自动重新取得仅追加出处和变化快照，保护已有人工题名、摘要、正文、可见范围与核对状态；内容不变时不制造新版本。受限重复不会转为公开条目。快照随资料历史、可读内容包和完整备份保留；离线包分别提供清洗阅读页和未执行的原始响应字节，迁移恢复仍使用完整备份。实现与当次检查见 [#62](https://github.com/normaltank/DataBase/issues/62) 和 [开发验证](work/LIIA自动采集开发验证.md)。

新采集文章首次成功取得页面后，以启用来源的当前有效管理员身份自动排一次现有作者关联建议；只覆盖本次新建的外部资料，不扫描既有全库。取得失败保留原题录，后续同轮重试成功后再排队；重复巡检不新增相同任务。来源停用、排队账号停用／改密或目标变化会阻止旧任务继续；作者依据不足可留缺，不阻碍阅读。ORCID和明确逐作者个人页仍只是有据候选，正式作者关联由成员人工采用；自动任务不把资料标为已核对。默认分享包仍不开后台、不扩大启用来源，按[便携说明](docs/portable-preview.md)显式配置后才持续运行。

## 自动中文整理与月费用

启用公开来源后，同一独立后台会为实际取得并保存的公开资料安排题名／原摘要翻译、研究对象国／主题／类型分类。后台只发送取得依据中的公开字段，已有人工修改、内部报告和受限资料不自动发送。结果保留机器标识、输入及规则版本、模型与依据，直接用于中文阅读和检索；已有人工中文、国别和主题优先。分类类型独立保存，保持原记录类别与权限。

没有原始摘要时继续显示缺失；来源网页说明不作为摘要。只有具有明确取得依据的实际作品正文，才能生成独立标识的“机器概述”，放在摘要附近；展开可查原文版本、引文和字符位置。当前 LIIA 适配器只取得网页说明，尚不提供所指作品正文，因此不会由这些说明生成概述。GSSC 已辨认的实际 HTML 正文可进入该概述流程；两个 OJS 期刊只翻译实际取得的题名／原摘要。按需原文件／全文翻译仍见 [#65](https://github.com/normaltank/DataBase/issues/65)；BJE／Crossref持续更新、纠撤稿等仍见 [#66](https://github.com/normaltank/DataBase/issues/66)，本轮未完成其范围。

运行管理员先按[模型和价格配置](#单篇辅助中文翻译)在启动环境设置凭据及价格版本，再进入“维护界面”→“中文处理与费用”设置月额度及匹配币种。未配凭据、价格或有效额度时不发请求，原文和公开采集继续。正式 DS 凭据、真实价格合同及月金额需要运行管理员另行配置；本轮仅用合成服务和模拟金额验证，没有启用真实付费服务。

所有 AI 调用，包括既有显式单篇翻译，共用本地月上限。调用前在短事务内按完整输入、保守 token 上界和最大输出原子预留，网络结束后按有效用量结算；最多两次同时占用。账期按发出时的 UTC 月份冻结，改价格不重估旧预留，切换币种不能绕过本月账本。页面展示本月已记录、待核占用、旧月份及逐次调用依据；本地估算不是供应商最终账单。

额度不足或配置暂不可用时，先读原文；后台每30秒巡检，配置恢复或新月后自动续作。完整但结构错误／截断的响应保留已有费用，按退避限制尝试；同一实际输入每轮最多三次供应商调用，换请求编号不增加次数。管理员处理异常后，在“AI任务与异常”填写依据并“批准受控重试”，以审计授权开启新一轮；每次仍重新核查预算和材料，旧尝试及费用继续保留。

认证（401）、余额（402）、速率（429）、服务（500／503）、传输与结构错误分别记录。缺少可信用量、发送后失联或中断时，全部预留继续占用；时间经过、租约到期、重启和跨月均不等于免费。管理员须展开费用依据，先确认请求已结束并核对账单，填写已核实金额及依据；仅有明确未发送／未计费证据时填零。核实后任务再按当前额度及重试轮次续作，不能通过重开清空未知费用。升级前运行中旧调用也需核实，并保守计入核实时当前月。

后台任务持久保存，120秒租约到期可重新领取，旧领取者不能写回新领取者的结果；费用未知任务保持暂停。内容包保留有权读取的原译、分类、概述与原文定位，独立 ZIP 校验器检查概述引用对应保留正文；全局费用账本与管理员审计只在完整备份中保留。完整恢复检查账本及原文对应，新目录启动不会盲目重发已发送但费用未知的调用。软件验证范围与复跑入口见[施工说明](docs/施工说明.md#自动中文整理与费用控制2026-10-2863-开发验证)，集成及最终放行以 [#63](https://github.com/normaltank/DataBase/issues/63) 为准。

## AI 自主维护

启用 AI 后，后台逐批整理新旧公共外部文章、人物和来源档案。普通提交、RIS／网页题录保存和自动采集进入同一路径，无需读者打开资料页。依据实际公开材料补充或修正作者、机构、刊物、标签、简介与适用编号，正式保存后即可查找和阅读；内部成果、受限资料、附件及来源内部备注不发送供应商。

“维护界面 → AI 自主维护”显示运行、暂停或缺配置、待处理数量及近期正式修改。需要指定对象时展开“指定一篇文章”；通常无需逐条排队。费用、搜索和网页取得共用现有暂停与月额度，在“中文处理与费用”配置。未变化的对象不会每次巡检重跑；资料或关系版本变化后重新处理，稳定对象约30天复查。暂停、停机和重启保留任务与已结算步骤，未知费用继续阻止自动重发。

新文章不再同时自动生成旧作者候选。旧显式建议入口及其采用／拒绝历史继续可用；以下两节说明这些兼容操作。AI 新建来源只维护档案，持续采集仍须在“自动采集”另行启用。便携版的本机启用、无密钥分享与恢复方式见[便携说明](docs/portable-preview.md#可选ai与后台维护)。开发合成验证及待统一验收状态见[#130](https://github.com/normaltank/DataBase/issues/130)。

## 作者关联建议（兼容显式操作）

阅读外部资料时展开“作品署名与文章单位”，点击“作者关联建议”→“取得作者建议”。平台根据明确DOI取得Crossref逐作者题录，或读取文章页的作者标识及明确个人主页，并有界补取ORCID公开person。后台结束后自动显示原署名、已有作者／新建有据人物及关联本篇的建议；展开“查看实际依据”核对实际材料，勾选后采用或拒绝。同名候选须明确选择身份或新建，全部新增关系都由人决定，ORCID也不免确认；没有依据继续保留未确认署名，不影响阅读。

文章单位与任职分别有据、分别勾选，机构署名仅复用已登记机构。发布者和文章单位不自动转成任职，不新增国籍。采用保留原署名顺序、既有人工确认、纠正与移除，不把资料标成已核对。冲突时保留当前选择；原“整理署名”、历史恢复及人物合并／拆回入口继续使用。

管理员在“中文处理与费用”点击“批量整理作者建议”，查找并明确选择1—20篇适用资料排队；只处理所选组。单次最多六次材料请求（失败也计数）、45秒、每份1MiB／总4MiB，不自动网络重试。多作者优先接续此前未取得的主页，覆盖及剩余数如实显示；单次署名整理沿用100项上限，超过部分保留原材料并说明未完成。暂停、月额度、未知费用和调用次数仍走统一网关。已拒绝同一材料建议不因无关档案修订重复推荐或收费。

“导出建议与依据”、可读内容包及完整备份保存原字节、URL、时间、hash、机器输入和人工决定；恢复重新校验目标、原件及历史。当前实现与实际检查入口见[施工说明](docs/施工说明.md)、[#64](https://github.com/normaltank/DataBase/issues/64)，真实小样与合成验证的区别见[材料说明](tests/fixtures/author_suggestions/README.md)。本轮未开启真实付费服务、修改真实库、打包或部署。

## 来源档案 AI 建议

本范围已由[PR #94](https://github.com/normaltank/DataBase/pull/94)交付；以下说明功能与调用边界，当前任务状态仍以 GitHub 为准。

在既有机构、期刊或其他出版物档案点击“AI补全”，选择“取得AI补全建议”。平台从已登记官网取得少量同站介绍／联系／编辑部页面；已有 ISSN 的刊物可补取一个 Crossref 期刊题录。缺官网、取证失败或依据不足时保留原档案，页面显示可处理的原因。管理员可在“来源维护”点击“AI批量补全”，明确勾选最多20个既有档案；不会自动扩大到全库。

任务在后台独立执行，关闭页面后仍可接续。页面自动显示终态结果，逐项对照原值与建议值、展开实际片段与原页，再勾选采用或拒绝。采用形成公共档案修订，仍待核对；他人改过档案时保留建议和选择并提示冲突。主办与出版分别有据，尚未唯一登记的机构保留为“机构待匹配”，先核查／登记机构后重新取得；不会代建未经确认的机构或混用角色。

所有请求使用同一 AI 费用网关和暂停、月额度、次数及未知费用保护。应用启动的既有后台同时接续显式建议队列与自主维护；独立 `python -m platform_app.ingestion --data-dir DATA_DIR --once` 也可处理队列。取证最多4页、深度1、每页1MiB／总计4MiB、总时限45秒、单次取得不自动重试；已持久化输入的后台续作复用原材料，180秒租约到期可恢复领取。页面“导出建议与依据”、可读内容包及完整备份均保留实得响应与采用／拒绝来历；完整恢复验证目标绑定、原字节及历史，不盲目重发费用未知调用。

本轮只用隔离合成库、模拟供应商和免费公开取样验证，没有开启真实付费服务、打包或部署。范围和统一交付状态见 [#93](https://github.com/normaltank/DataBase/issues/93)、[固定规格](docs/specs/档案筛选与AI辅助维护.md)及[施工说明](docs/施工说明.md)。

## 从官方来源发现近期资料

在 LIIA、GSSC、CJIR 或 Intersections 的既有来源档案选择“发现近期资料”，再点“手动取得最近 30 天”。LIIA 使用 Opinions RSS，GSSC 使用 Publications 当前 HTML 列表，CJIR 与 Intersections 使用各自官方 RSS。页面显示来源、入口类型、服务端取得时间、包含当日的 UTC 30 天窗口、返回条数、最早有效日期和排除原因。LIIA 与 GSSC 按入口给出的发表日期筛选，期刊 RSS 按上线／发布标签日期筛选；后者不替代原文发表日期、引用年份或首次入库时间，保存前须核对原文题录。当前响应不代表完整历史或全部栏目；LIIA 订阅通常只有最近 20 条。

选择“核对本条”进入既有资料表单，可编辑题名、日期、类型、摘要及来源后“保存本条并接续”，也可逐条跳过。默认类别为“其他”，不会把广播介绍变成论文；署名、语言和摘要缺失保持空白。“来源公开描述”可能只是系列介绍，须核对后才可人工补入摘要。取得不抓取单篇正文、图片、PDF 或广播，也不会自动翻译、确认身份或标记已核对。

切换、关闭和刷新后，整队列及逐条编辑保存在当前账号的浏览器草稿；从同一来源按钮或“我的草稿”续作。重新取得须明确确认替换当前队列；新请求或保存失败保留已有输入。保存前后会检查当前网址／DOI 及候选身份，重复可打开核对，受限重复只给通用提示。再次发现不会覆盖既有内容、译文或核对状态。

保存后在详情“来源发现依据”查看栏目、固定入口、取得时间、窗口、原始候选及采用字段；它们随历史、可读内容包和管理员完整备份保留。当前新增来源范围见 [#103 固定范围1.0](https://github.com/normaltank/DataBase/issues/103)。LIIA 首版的[试点规格](docs/specs/拉脱维亚来源发现试点.md)与[开发验证记录](work/LIIA近期发现开发验收.md)保留其当时范围。

## 用 RIS 文件逐条提交题录

在资料库点击“导入 RIS 文件”，选择 UTF-8（可带 BOM）的 `.ris` 文件后预览。每文件最多 1 MiB、100 条，首版接收 JOUR、RPRT、WEB／ELEC、GEN；未支持类型与损坏条目显示问题，可查看原文或跳过，预览不会写入资料库。

点击“核对本条”沿用资料表单修改题名、原始署名、日期、刊名、卷期页码、ISSN 等；年份与年月保持原精度。不能解析的日期需人工修正或明确确认暂留空。人物与来源候选只作线索；身份确认仍须选择档案、勾选确认并填写依据。没有确认人物时，原始署名保持待确认。

每次点击“保存本条并接续”只保存当前一条，队列保留已保存编号；其余条目可以继续核对或跳过。可见重复显示候选，保存时再次检查 DOI、规范化网址及本预览条目重试。保存结果不明时使用“重新核对当前字段与保存结果”，再决定后续处理。失败与切换条目保留编辑，关闭后可从同一入口或“我的草稿”恢复整队列；替换文件需明确确认。

新资料仍为中心共享、待核对。详情“RIS 交换依据”保留本条原文、有序标签、文件名、文件摘要、序号和采用字段，修订、历史恢复、可读内容包和完整备份继续保全。原文件整体及其他条目不会进入该资料；文件内的 URL、附件标签和本机路径只作依据，不会自动访问。本轮范围见[标准题录交换规格](docs/specs/标准题录交换.md)。

### 导出选中的 RIS 题录

在资料库勾选 1—100 条资料，点击“导出选中 RIS”。服务端按同一读取快照检查当前状态与权限；有失效、无权读取或不支持的条目时整次失败，页面保留选择供调整。期刊文章为 JOUR，外部报告为 RPRT，仍为“其他”的已导入 WEB／ELEC 为 WEB，其余外部资料为 GEN。个人成果、研究笔记、摘录和目录译稿使用内容包导出。

文件是 UTF-8、CRLF 的当前题录：题名写入 TI，当前已采用中文题名写入 TT；原题名与题名不同时，以 `N1  - Original title: …` 保留。未采用机器译文不写入。当前署名文字与有效结构署名逐项一致时，按顺序输出每条 AU（包括待确认和机构署名）；不一致或尚未拆分时整行保留，不猜逗号或姓名边界。年份／年月保持精度，页段、文章号、多 ISSN 和缺项继续保留；清空的字段不会从旧原始题录补回。

RIS 不包含正文、附件、身份确认、权限、历史及未映射标签，不是无损备份。需要完整原译版本与交换依据时使用可读内容包；迁移全部状态使用管理员完整备份。开发验证与复跑入口见[本轮验收](work/RIS选中导出开发验收.md)，交付状态以 [#52](https://github.com/normaltank/DataBase/issues/52) 为准。

## 简单资料夹与旧内容

在“我的 → 资料夹”新建资料夹，只填写名称、简短备注和个人／中心共享范围。展开“添加已有资料或成果”查找并加入已收录内容；移出只解除资料夹关联，原资料仍保留。同一内容可以进入多个资料夹。只有创建者可改变资料夹可见范围，共享夹的内容仍逐条遵守资料本身的读权。

旧专题的研究问题、比较笔记、阶段判断、排查日志和排除项保留在“已有研究内容”；有内容时可从“编辑资料夹”必要修订。“修改历史”能够恢复当时字段与条目关联，保持当前可见范围；“导出资料夹”保留可读的已有研究内容及引用文件。空资料夹不显示研究项目模块，旧排除项不会自动改为已纳入。

## 档案、成品成果与共同维护

从机构、期刊或其他来源详情维护介绍、导入已完成目录译稿；每份译稿独立保存题名、编译者、年份／卷期或跨期范围、网页正文、原目录出处和附件。一般关联来源可以多选，表示内容与这些来源有关，不自动填写为发布机构。来源页、资料库、专题和检索访问同一份记录。正文与来源介绍、别名可以检索；本地附件文字检索见下节，OCR 尚不包含在内。

来源目录的“筛选条件”分别提供机构类型、期刊主办国别、国际定位和收录范围；已经应用的条件可以单独移除。来源和人物详情的“本页内容”可以跳到相应章节，保留当前查询页面。人物的修改历史、比较合并和身份整理历史位于“历史与身份整理”，编辑与导出直接可见。

点击来源名称进入机构、期刊或其他出版物的独立研究档案，可复制地址再次打开；“快速预览”便于在目录中查看，关闭后继续原来的筛选。机构档案展示适用的信息、机构关系与任职人物；期刊显示主办方、出版方、主办国别、国际定位及 ISSN。公共介绍继续通过“编辑来源”共同维护，历史与纠错入口在“历史与维护”中。

档案把机构发布／刊物刊载资料、一般关联资料、目录译稿和中心成果分区展示。明确以该对象为研究对象的笔记另行汇集；一般关联或引用并不自动成为这类笔记。数量与分页只包含当前成员可见的内容；暂未收录不代表对象没有成果。资料、译稿及笔记仍访问同一份记录，编辑权限按原有规则执行。

目录译稿由所有有效成员共同编辑。保存发现他人已有新版本时，保留输入并对照最新内容后明确继续处理。草稿按账号保存，关闭或刷新页面后可从“我的草稿”继续；选中的完整附件也会保留。网页正文支持标题、段落、列表、表格和链接；Word／PDF 作为独立附件，不在网页中修改文件本身。

个人编译成果和个人研究报告分别记录署名、负责作者账号和上传者。本人提交直接确认；替别人提交时选择负责作者，由该作者本人确认后生效。正文仅已确认作者及其授权同事可修改或恢复；管理员身份本身不授予个人报告正文改写权。旧个人报告先显式认领或指定作者确认，不自动把旧提交者当作作者。授权与共享范围由负责作者调整，恢复历史不恢复旧权限。

外部资料、研究笔记、阅读说明、摘录、目录译稿及公共档案由当前有权读取的有效成员共同编辑和恢复；编辑时保留修改人及版本，冲突时保留输入。普通共编者不会获得可见范围或授权名单的管理权。旧笔记的负责作者与确认历史继续保留，未确认不妨碍可读成员共同编辑；原可见范围管理沿用其已确认负责作者。个人收藏、常用检索、私人资料夹和草稿仍属于个人工作空间。

成果导入接受个人编译成果、个人研究报告和目录译稿。原文件作为独立附件保留；网页正文可粘贴已有内容并必要修订，添加新版文件不改写旧文件字节。正文历史记录当时附件集合，恢复形成新版本；完整备份保留仅在历史中使用的原文件。平台不在线修改 Word／PDF，也不提供分步报告写作或报告生成器。

已有笔记、阅读说明、摘录与报告仍可从原资料、档案、资料夹及检索中阅读、必要修订、查看历史及导出。没有旧内容时不显示空研究模块，阅读和档案页不再提供新建研究笔记或摘录的专门流程。未提交的旧草稿继续可恢复，原句、位置、原文关联和所选附件保留；当前普通录入与修订草稿从“我的 → 未提交草稿”接续。

成果关联原文支持搜索与翻页；未入库出处可先填写。疑似重复先比较影响再人工确认；合并保留旧编号、历史及现有引用，权限、类型或快照冲突时拒绝合并。平台不会自动批量合并真实试点资料。

### 报告引用用途与变化提示

有既有采用笔记的个人报告或编译成果，必要修订时可调整已有引用的主要用途（支撑、反例、限定、背景或未分类）及所涉判断。新成品导入使用原文关联与出处，不提供组织摘录写报告的流程。保存遵循报告负责作者及授权同事的权限；冲突时保留当前输入，历史恢复同时恢复用途、说明和当时快照。

报告阅读页区分笔记修订、原文修订、原文合并转向和身份关系变化。身份提示还说明原文署名、文章署名单位或笔记研究对象的当前端点／确认状态改变，或关系历史已修订。人物介绍等档案正文修改不会单独触发身份提示；历史没有身份基线时显示无法比较。这些变化需要人工评估，不表示旧结论已经错误。

报告的采用内容继续固定。勾选“明确更新所选笔记为当前版本”才采用新笔记；若该笔记仍引用旧原文，原文变化提示继续保留，须先在笔记中明确刷新原文。页面、复制引用、内容导出、复核清单保留相同用途和变化原因；离线提示反映导出时状态。当前权限外的引用与关系细节被隐藏。只有当前可见的已登记引用全为支撑时，页面提示未登记反例或限定；混有未分类时说明登记情况未知。

### 附件文字检索

新上传的文本型 PDF、DOCX、UTF-8 TXT／Markdown 会在资料保存后尝试建立文字索引。资料库关键词同时匹配题录、正文和当前可读取附件；多个词可以分布在题录与附件中。命中结果注明附件名称、位置与文字片段，点击文件名下载原件核对。PDF 使用文件页码，可能不同于印刷页码；DOCX 仅提取正文段落与表格行；TXT／Markdown 使用行号。自动提取文字不属于人工研究摘录，也不会改变报告已有引用。

附件命中旁点击“查看命中位置”，可查看该位置的完整提取文字并下载原文件核对；不会因此创建研究摘录。已有摘录的原句、译文、解释、位置与采用版本继续可读、必要修订与导出；固定附件锚点仍用于核对所据字节与位置。

摘录修订原句或位置会重新检查附件文字；原文题录及版本只在改选依据或明确刷新时更新。报告继续保留采用时的摘录及附件锚点，旧快照没有锚点时显示未知。

旧附件及恢复备份后的附件：打开资料详情，在“附件文字检索”中点击“建立索引”或“重建索引”。当前有权下载该附件的成员均可执行；重建不修改正文、版本或授权。页面分别显示未建立、已建立、无可提取文字、格式不支持、超过限制或提取失败。扫描图片不执行 OCR，加密 PDF、损坏文件或提取失败仍可按原方式下载。

每份索引最多处理 10 MB 文件、300 页 PDF、20 MB 解压内容、100 万字符、2 万个位置片段，限时 12 秒；上传仍保留原有 20 MB 上限。PDF 的排版顺序及混合图片可能导致提取不完整；DOCX 的图片、脚注及文本框不在本轮提取范围。普通搜索只读已有索引，不触发解析。仅当前附件参与检索，历史恢复、合并及权限变更会即时改变可搜索范围。

文字缓存存于数据目录的 `attachment-index/`，可丢弃且不随完整备份导出。原数据库和附件仍是备份依据；恢复至新目录后逐份重新建立索引。尚未建立索引时，附件文字不会命中，原有题录及正文仍可检索。

## 作者目录与人物档案

从“作者目录”按原名、中文名或别名查找，也可先建立尚未关联作品的人物档案。同名人物分别保存；显示姓名、姓名写法、分节介绍和参考出处由有效成员共同维护，每次保存填写维护依据或说明。人物身份与成员账号分开。

目录可分别多选“任职机构国别”和“作品研究对象国”，与姓名条件组合。任职国别包含有据登记且未移除的历史、时间未知任职；作品对象只取当前账号可见、原始署名来源同样可见的已确认作品，人工研究对象优先，适用时回退有效自动分类。两个维度各自多选为 OR、相互为 AND；未知入口说明当前登记或可见作品信息不足，不能据此判断国籍或是否有研究成果。

在原始资料中打开“整理署名”，保留原始整段文字，再逐项填写署名片段、调整顺序，并选择人物或机构档案。目录与候选显示已登记的简介和机构线索，同名时需核实后选择；“任职登记”包含有据的历史任职，不表示当前或唯一单位。已确认署名必须填写可核查依据，拿不准时保留待确认。机构作者与发布机构分别登记。普通同事可以共同维护有权查看的外部资料署名和正文。

从署名可进入人物或机构档案的已确认作品列表，再返回原资料；待确认项不计入已确认作品，搜索和数量按当前可见范围计算。认错时重新选择身份或退回待确认，移除后历史仍保留。“署名历史”可查看前后身份、依据和修改人，并单独恢复某一项；正文历史恢复保留当前公共署名，避免覆盖后来的身份纠正。保存冲突保留当前输入，关闭后可从“我的草稿”继续。

人物档案的“维护任职经历”可分别登记已有机构、角色与可核查出处，允许同时任职多家机构或在同一机构分段任职。起止时间可填 `YYYY`、`YYYY-MM` 或 `YYYY-MM-DD`，仅知道一端或完全未知时保留空白；页面明确显示时间未知，不据此推定现任。机构详情的“任职人物”可查阅、选择人物并维护其经历；同名选择器同时展示姓名写法和已登记简介。

资料阅读页的“维护文章单位”按本篇作品的具体署名登记一家或多家机构及出处。先在“整理署名”登记作者片段，再选择对应的第几项署名；各单位卡片保留署名序位并可进入人物或机构档案。文章署名单位、人物任职、机构署名作品和发布作品分别展示；修改任职不会改写旧文章单位，发布文章不会自动建立任职。任职与文章单位各有修改历史和单项恢复，移除保留来历；恢复正文历史保留当前关系。冲突时保留输入及本机草稿，对照最新关系后继续保存；公共关系维护不扩大资料或笔记的可见范围。

人物档案中的“写研究笔记”会预选此人；笔记编辑页可同时选择多个人物、机构和期刊。也可从档案“关联已有笔记”，选择自己当前有编辑权的笔记，继续调整研究对象。各档案汇集同一份笔记，移除一个对象保留笔记；引用原文或一般关联来源分别登记。研究对象与正文均由可读成员共同维护，既有可见范围保持。保存冲突会保留正文和对象选择，先对照最新内容再保存；“研究对象调整历史”可查看对象名称、类型、操作人和原始身份线索。

头像支持 JPEG、PNG、WebP，单张不超过 5 MiB，上传时填写来源链接或说明。替换、移除后，原头像仍随历史保留。输入无效或同时编辑发生冲突时，当前输入和待上传文件保留；对照最新版本后继续保存。关闭或刷新后从“我的草稿”继续，并明确选择恢复草稿。“修改历史”可查看修改人、依据和旧头像，恢复产生新版本。

确认两个档案属于同一人时，从人物详情打开“比较合并”，查找另一档案，核对两份介绍、出处及当前可阅读的作品和研究关联。逐项选择当前姓名、原名、中文名、介绍和头像，填写身份依据并确认；同名选项通过“保留编号的档案”和“合并到前者的档案”区分。未选内容及各条关系来历继续保留，当前和历史头像的原链接仍可用。旧编号仍可搜索、打开，并说明合并去向；编号不作为姓名写法展示。

“身份整理历史”可查看原合并、档案与可阅读的关系，并预览拆回。预览区分原有转接、后续新增、独立更正和已解除：只按本次合并来历恢复未被独立重新指定的归属，保留后续介绍、头像、任职字段、已纠正归属与解除结果。仅完善署名文字或任职角色不表示重新确认人物身份。新增任职逐条明确选择人物；新增作品可选择人物或保留待确认。若有依赖的后续合并，按页面顺序先拆后续，再从历史重新预览较早一次。

私人笔记不阻塞公共人物拆回。归属不明的受影响笔记关联保留原对象及来历，显示“研究对象待复核”，暂不计入人物已确认笔记；其他已明确的人物、机构或期刊关联继续有效。可读成员打开笔记的“复核研究对象”，可确认原对象、改选或移除。普通正文保存继续保留待复核状态，身份操作不允许查看或分配不可读笔记的关联。正文、原有可见范围和报告采用的引用快照保持，读者可查看身份更正依据。

介绍历史恢复不会拆回身份。预览后任何参与档案、相关关系、当前或原端点及身份记录变化，都须重新比较；页面保留分配选择和依据，重比后再次明确确认。笔记延后复核遇到版本冲突也保留选择，重新核对后再处理。

点击“导出人物档案”下载离线 ZIP，解压后从 `index.html` 进入该人物的姓名写法、介绍、出处、任职依据、当前与历史身份、作品和笔记关系。头像及可读取的附件使用包内相对链接；`content.json` 保留同一范围的结构化内容、稳定编号和版本。已确认作品／笔记、待复核笔记及已移除关系分别呈现，待复核不计为已确认。导出逐条使用当前读取权限，作者已共享的当前笔记可保留，不能读取的旧私人来历不会随历史带出。

## 成员与内容导出

管理员可创建本机成员、停用账号、重置密码；系统保留至少一位有效管理员。停用不删除署名或修订记录。密码至少 12 个字符；成员可修改本人的密码，重置或停用使旧会话失效。正式账号名单与备份排程仍由使用方确定。

资料库内容导出使用当前资料筛选，人物详情导出限定所选人物及其可读关系、身份历史所需的资料和引用，生成 ZIP：打开 `index.html` 阅读正文、来源介绍、专题和引用证据；`content.json` 保留结构化记录和关系，`attachments/` 保存有权读取的文件，`avatars/` 保存导出中引用的头像。可访问的所引笔记与原文一同纳入。此导出不包含账户凭据；需要恢复全部账号、历史及归档内容时，使用管理员完整备份。

解压后的 HTML 无需联网加载样式。正文、来源介绍、专题比较、原文旧快照及报告采用的笔记正文使用一致的表格边框、表头和留白；长链接可以换行，多列表格可在自身区域横向滚动。引用保持采用时的版本；新原文快照记录题名、作者、日期、链接、编号和版本，实际摘录另列。已下载的旧 ZIP 需重新导出才能采用新样式。

### 核查导出的依据与文件

新导出包的 `index.html` 提供复核入口。`review.html` 和 `evidence-coverage.json` 分别以可读页面和结构化清单说明：当前正文及附件、引用采用时的题录与摘录、实际包含的指定原文附件。只有外部链接、只有题录或普通笔记未固定原文时如实提示；当前内容不补作旧引用依据。附件缺失、大小或校验值与登记不一致时，导出会失败，先恢复或核实原件再导出。

`manifest.json` 列出包内文件的字节数及 SHA-256。使用 Python 3 运行仓库里的独立校验脚本即可检查，无需启动平台、登录或联网：

```text
python scripts/verify_content_export.py "research-content.zip"
```

可从任意目录运行脚本的完整路径。如果另有可信渠道提供整个 ZIP 的 SHA-256，可追加 `--sha256 该校验值` 对照。脚本只读压缩包，不运行包内文件。旧导出包没有清单时需重新导出；完整系统备份使用另一个恢复流程。

对于有附件锚点的新记录，校验器还交叉核对 `content.json`、`evidence-coverage.json` 的引用编号、附件路径、字节数和摘要与 manifest 及实际附件一致。缺失或不一致会返回非零退出码。旧记录没有锚点时保持未知，只执行其可支持的一致性检查。校验器不重新提取附件文字。

校验通过表示包内文件及已声明锚点与清单一致，不能证明来源真实、观点正确，也不能排除文件连同清单一起被改写。实际研究复核还须检查原件上下文、译法、反例和论证，见 [研究质量与复核](PRODUCT.md#研究质量与复核)。

## 来源目录的使用

来源目录提供机构、期刊、其他出版物及全部入口。机构可组合国家与智库、大学／高校、研究所／研究中心等类型筛选；类型描述机构自身，大学的下属研究单位不会因此成为大学。年鉴、工作论文系列和旧出版物登记在其他出版物中；资料发现网站也由“维护界面→来源维护”统一查阅，旧编号及关联继续保留。

期刊可组合筛选主办国别和国际定位。国别按主办关系及机构国家登记生成，出版方国家另记；缺失或冲突保持待确认。国际定位为是、否、未知，选择是或否需填写依据。切换主要类型会清除不适用的筛选。

机构详情可以沿有依据的隶属、共同设立、合作、资助关系双向浏览；编辑关系时说明方向、依据与核查日期。机构详情与编辑不显示 ISSN 等期刊字段。来源对象类型也可纠错，稳定编号不变；不适用字段保留在历史，尚有机构关系或主办／出版引用时先处理关联。原始 classification 仍保存原值。

本轮试用库有 58 个机构、44 个期刊、37 个其他出版物，另有 4 个资料发现网站。44 个期刊中，34 个可由现有登记推导主办国别、10 个待确认；国际定位为是 3 个、否 0 个、未知 41 个。这些不是中心已核对数量。具体数据依据和未决项见执行记录。

来源维护列表中的“资料发现网站”保存门户、机构目录与检索站等发现线索，当前不执行自动采集。机构、期刊的官网和资料目录地址继续保存在各自档案，无需另建一份身份。未来采集也可以从这些官网的文章列表、刊期页或订阅地址开始，具体采集规则另行建设。

- `data/platform.sqlite3`：来源、资料、成果、关系、账号、收藏、专题、历史。

不要只复制数据库而遗漏附件。程序源码和说明需另行一并交接。

## 备份与恢复

管理员登录后进入“维护界面→完整备份”，点击“下载完整备份”。备份包含所有账号的个人/共享/受限数据、密码散列、关联、历史、平台上传附件、当前与历史人物头像，以及身份事件、旧编号和拆回依据，由管理员保管。协作负责人的资格及其历史、主题参与关系、选题报告、会议决定、编译稿与退回意见的全部版本及原件，以及当前阶段、人工转换、结束／重开状态与事件、确认依据和旧期升级来源也进入完整备份。后来移出参与者或撤销资格不使过去合法交接失效，恢复后当前操作仍重新鉴权。人物、署名、任职、文章单位、身份操作及协作结构各次增量升级前自动生成完整备份；旧版备份恢复到新目录后，由新版应用继续增量升级。

也可以在本目录执行：

```powershell
python -m platform_app.maintenance --backup data
```

恢复必须使用一个**尚不存在的新目录**，不会覆盖正在使用的数据：

```powershell
python -m platform_app.maintenance --restore "D:\备份\research-backup.zip" --target "D:\Agent Workspace\DataBase\data-restored"
python app.py --data-dir "D:\Agent Workspace\DataBase\data-restored" --no-import --port 8849
```

打开 `http://127.0.0.1:8849` 验证恢复结果。恢复工具校验备份内文件散列、数据库完整性、外键、当前与历史头像及附件引用，还检查人物转向、关系历史端点与连续版本、身份事件前后关系及依赖、拆回分配和幂等结果的一致性；校验失败不会发布目标目录。会话密钥不会随备份转移，恢复后重新登录。完整数据备份不包含 ThinkTank 原目录中的未迁移附件。

## 在另一台机器启动 / 开发

恢复工具兼容结构版本 1—26。新版本启动时增量迁移旧库，有数据的每个升级阶段先生成完整备份；不会重新导入覆盖已有资料。备份包括仅由历史版本引用的上传附件及个人常用检索。恢复演练始终使用新目录，切换实际数据目录前先核查正文、附件、关系与历史。

需要 Python 3.10 或以上。当前已在 Python 3.12 上验证。前端无安装、编译和外部 CDN 依赖。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\start.ps1
```

首次启动时会尝试从默认 ThinkTank 路径导入；该目录不存在时使用现有平台数据或空库，可手动提交。可指定其他资料目录或仅启动现有数据库：

```powershell
python app.py --source "D:\另一个位置\LatviaResearchDatabase"
python app.py --no-import
```

若端口被占用，使用 `start.ps1 -Port 8080`。启动器会复用已正常运行的服务。`stop.bat` 仅停止由本项目启动器记录且命令路径匹配的后台进程；手工执行 `python app.py` 时用该终端的 Ctrl+C 停止。

`GET /api/export/content?person=<人物编号>` 是人物详情所用的可读导出入口；旧人物编号按当前身份解析，空参数返回 400，未知编号返回 404，均不会退回全库导出。身份与关系的读写及本轮稳定版本约定见 [首版验收记录](work/人物Wiki首版开发验收.md#操作契约与后续衔接)。

`POST /api/intake/preview` 接收 `{ "input": "DOI 或文章网址" }`，需要登录及当前 CSRF，返回字段、原始署名、重复与档案候选、取得依据和绑定当前成员的签名凭据，不写正式资料。确认后的创建仍使用现有资料保存接口。网络边界、支持范围和验证见[辅助录入验收](work/链接与编号辅助录入验收.md)。

修订接口需要传入当前 `version`，防止覆盖同事已保存的新版本。编辑者不得通过接口自行扩大授权；管理员核对接口与备份接口也在服务端检查角色。

`/api/saved-searches` 提供个人检索列表和创建，`/api/saved-searches/<id>` 提供读取、带版本的修改及删除。资料查询传入 `saved_search=<id>` 时以该账号保存的条件为准，只允许另行指定页码与每页数量；列表及导出继续执行当前权限检查。`GET /api/record-candidates` 按原文／专题用途先筛出合格资料，再计数和分页，避免先截断后过滤。

## 自动验证

安装测试依赖后，在仓库目录运行统一检查（应用运行仍只需 `requirements.txt`）：

```powershell
python -m pip install -r requirements-test.txt
python scripts/check.py
```

该入口检查应用、维护脚本和测试的 Python 语法，再发现并执行完整合成数据套件。测试使用独立临时目录；入口始终关闭外部资料测试，包括当前终端曾设置外部检查开关的情况。语法错误、测试失败、未发现测试或全部跳过均返回非零退出码。

直接运行 `python -m unittest discover -s tests -v` 时，外部资料测试同样默认跳过，连 ThinkTank 目录是否存在也不会探测。需要单项调试时，可使用 unittest 的 `-p` 或 `-k` 筛选；交付验收使用完整入口，或核对覆盖范围后全部分片的执行结果。

[GitHub Actions](.github/workflows/check.yml) 在推送和 PR 时，使用 Python 3.12 执行校验，令牌仅有读取仓库内容的权限。Ubuntu 在10分钟预算内运行上述默认完整入口；Windows 按完整模块分成两个并行检查，各有30分钟预算，模块内保持原发现次序及类、模块准备与清理边界。分组依据发现的用例数量确定，不保证两组耗时相等。

需要在本机查看计划或单独复跑某片时，运行：

```powershell
python scripts/check.py --plan --shard-count 2
python scripts/check.py --shard-index 1 --shard-count 2
python scripts/check.py --shard-index 2 --shard-count 2
```

计划模式检查语法和完整发现，核对两片无交叠、用例ID多重集合并集与完整套件相等，输出数量与SHA-256摘要；它不执行测试，不代表校验通过。执行分片仍检查全部源文件语法并禁用外部资料；空片、非法参数、失败及整片跳过均返回非零。CI 用 `--expected-plan-digest` 绑定实际执行与预先核对的计划。原必需检查名 `Python 3.12 / windows-latest` 保留为总放行检查，只有两个分片均成功、实际检出提交与事件提交一致、覆盖计划相同时才通过；取消、跳过、缺结果或缺摘要均不放行。每片保留实际执行／跳过数量、总耗时与最慢10项信息。结果以对应提交的实际检查记录为准；配置和规划数量不代表某次执行已经通过。

辅助录入的定向浏览器回归为 `python scripts/check_intake_preview_browser.py`，需另有 Playwright 和 Chromium；可用 `DATABASE_BROWSER_EXECUTABLE` 指定浏览器。脚本只在空闲的 8851 端口启动临时合成库，模拟题录服务，不访问真实资料或外部站点；它不包含在上述无浏览器的合成套件中。

RIS 导出的定向检查为 `python -m unittest tests.test_ris_export -v`，强制使用固定测试依赖 `rispy==0.10.0` 读取实际 HTTP 下载并比对预先固定的合成期望；缺依赖会失败，不能静默跳过。真实浏览器复跑为 `python scripts/check_ris_export_browser.py`，另需 Playwright 与 Chromium，端口 8862 必须空闲；仅启动临时合成库，完成 1366px／390px 选中下载、失败保选择、权限变化与跨账号迟到响应。可用 `DATABASE_BROWSER_EVIDENCE` 指定新建的证据目录；此目录包含合成库及截图，留在本机。

### 单独检查真实资料导入

只有在已获授权、确认[四张试点主表](#初始数据及其边界)可供此次验证时，才在 PowerShell 显式开启并单独运行原外部测试：

```powershell
$env:RUN_THINKTANK_IMPORT_TEST = "1"
try {
    python -m unittest discover -s tests -p test_platform.py -k real_import -v
} finally {
    Remove-Item Env:\RUN_THINKTANK_IMPORT_TEST -ErrorAction SilentlyContinue
}
```

该测试先检查默认资料目录是否存在；缺失则跳过，存在时读取指定主表，对导入前后散列、幂等性和关联进行验证，输出使用临时数据库。普通检查与 CI 均不执行这一项。

当前已实现 LIIA Opinions、GSSC Publications、CJIR 与 Intersections 的固定入口持久采集及受费用控制的自动中文整理；其他来源仍需分别接入和启用。附件 OCR、实时协作、正式网络部署、对外发布和高级分析仍未提供，当前实现与验证范围见[施工说明](docs/施工说明.md#文档职责与当前状态)及[自动中文整理说明](docs/施工说明.md#自动中文整理与费用控制2026-10-2863-开发验证)。软件实现不表示真实库已升级或正式服务已部署。

## 单篇辅助中文翻译

打开已保存的外部单篇资料，在“辅助中文翻译”中创建任务，再点击“执行本篇翻译”。仅发送该篇原题名（没有原题名时使用题名）和摘要到 DeepSeek；摘要为空时只译题名。任务和机器版本独立保存，页面打开、数据库启动及备份恢复均不执行付费调用。

运行管理员在启动进程的环境中配置 `DEEPSEEK_API_KEY`；可选 `DEEPSEEK_BASE_URL`（默认 `https://api.deepseek.com`）和 `DEEPSEEK_MODEL`（默认 `deepseek-flash`）。题名与摘要翻译明确发送 `thinking.type=disabled`，不依赖供应商默认模式。自定义地址必须为可信 HTTPS 服务；调用沿用系统代理与 TLS 证书信任，禁止携带鉴权跳转。凭据只放运行环境，不写入仓库、数据库或页面。

截至2026-10-28，官方接口支持 `deepseek-flash`、`deepseek-v4-pro`；旧 `deepseek-chat`／`deepseek-reasoner` 已公告退役。正式运行前按[官方模型与价格](https://api-docs.deepseek.com/quick_start/pricing/)及[接口参数](https://api-docs.deepseek.com/api/create-chat-completion/)核对配置。可设置 `DEEPSEEK_CONFIG_VERSION`（默认 `translation-nonthinking-v1`）与 `DEEPSEEK_MODEL_VERSION`（未设置时留缺），每次调用保存配置版本、请求模型、响应模型及供应商指纹。

价格通过 `DEEPSEEK_PRICING_JSON` 配置，必须含字符串字段 `version`、`model`、`currency`、`input_cache_hit_per_million`、`input_cache_miss_per_million`、`output_per_million`；模型须与当前模型一致，币种用三位大写代码，金额为每百万 token 的非负十进制字符串。按实际合同及峰谷时段选择并命名有效价格版本，调用依据保存该配置快照。没有内置价格；缺少有效价格或匹配月额度时不发送。显式任务也使用[统一费用控制](#自动中文整理与月费用)。

每次执行读取最多 256 KiB 响应，网络超时为20秒。显式单篇任务不自动重试，失败后可显式排队，同一任务最多执行三次；中断任务满60秒可重新排队，但费用未知时共享网关仍会阻止再次发送。新建请求也不能绕过输入级次数和预算。译文与原题名／摘要对照显示，校订后点击“采用此版本”才写入独立人工中文字段。原资料版本变化时需重新生成；重复生成保留已采用和后续人工修订的中文。成员可通过“编辑内容”继续校订，通过修改历史恢复。

只有供应商明确以 `finish_reason=stop` 完整结束且内容结构有效时才保存成功译文；截断、资源中断、被取消、缺少或未知结束状态均保留失败。每次执行已返回的用量、模型与结束状态分别保存，失败或重试不会清掉先前依据；未得到完整用量的请求保持未知，不据此声称没有费用。调用依据随详情、内容包及完整备份保留。

CSV 与可读内容包包含有权读取的原译对应、机器来源及版本；可读内容包另含人工中文修订历史。完整备份保留任务状态和所有版本，恢复后仍需显式执行。机器译文标识与软件测试不能证明专业术语、材料真实性或研究结论已获人工核对。

定向浏览器验证使用 `python scripts/check_translation_browser.py`，需 Playwright 和 Chromium；通过 `DATABASE_BROWSER_EXECUTABLE` 指定浏览器，可用 `DATABASE_TRANSLATION_EVIDENCE` 指定截图和结果目录。脚本使用临时合成库、动态本机端口和外部 HTTP mock，覆盖 1366／390 宽度的创建、执行、校订采用、冲突保留输入和晚到响应。

阅读稳定性的定向验证为 `python scripts/check_reading_stability_browser.py`，默认占用空闲端口8904并新建临时合成目录；覆盖空访问后的刷新／重登、补译分页与精确确认、撤权后保留条件重读，以及390px与200%放大。可用 `DATABASE_BROWSER_PORT` 更换端口。
